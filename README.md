# 浮生 · 摸鱼桌面

一个可以安静陪伴工作的互动桌面，已集成「锦鲤池」「赶海」「猫咪庭院」三个主题。沿用 React + Canvas 2D / WebGL + Electron，与用户提供的手绘水彩素材保持一致。

**V3.0** 集成「锦鲤池」「赶海」「猫咪庭院」三个主题，应用版本为 **3.0.0**。加入猫咪外观定制、六种道具、四季与日夜、庭院声音，以及共用四足步态、树下光影和准确对准猫粮的进食停靠。原有三个主题的本机存档继续保留。发布内容见 [V3.0 发布说明](docs/RELEASE-V3.0.md)；[V2.0](docs/RELEASE-V2.0.md) 与下方 2.x 条目作为历史记录保留。

本次漂流瓶更新：每轮自然涨潮、或手动由退转涨时来一瓶；同一段涨潮内重复点击、重载或切换主题不会重复生成。已有未拾取的来信瓶会保留，不替换、不叠加。29 封来信不重复，收齐后停止投放；离线经过的涨潮不会补发。

## 2.8.0 四肢步态与树下光影

猫咪行走改用共用的四足步序与独立关节：以实际路程推进脚步，支撑脚留在地面，摆动脚抬起再落下。转向或脚点超出腿的伸展范围时重新落脚，身体不再随平地步频上下弹跳；石阶、木廊和草垫之间的真实高度跳跃继续保留。各外观使用自己的毛皮材质，已有猫咪与存档继续兼容。

樱花与其他季节树冠增加与原画对齐的透明前景，猫咪经过时被花叶局部遮挡，花叶空隙仍可透出猫身。猫咪明暗随树荫和日夜变化；脚底接触影与躯干投影跟随落脚位置，起跳时阴影留在地面。树冠素材合计约 95 KB，采样与合成结果缓存复用。

动作仍为手绘素材上的二维关节动画，朝向来自前、后画稿与左右镜像，并非任意角度的三维猫模型。光照改在小尺寸猫咪缓冲区内合成，降低多猫同屏的绘制成本；实际运行检查、4K 采样条件与限制见 [2.8.0 验证记录](docs/CAT-LOCOMOTION-2.8.md)。

## 2.7.5 小院的风与鸟鸣

设置中的「庭院声音」加入轻柔持续的微风底声，使用柔化后的风吹树叶录音无缝循环。白天偶尔响起真实小鸟叫声，猫咪约隔 70–150 秒轻轻喵一声；各类环境声错开，手动互动的反馈优先。夜间鸟鸣收起，保留更稀疏的轻虫声，冬夜关闭虫鸣。

微风与单次互动音效分别管理，共用原有音量与静音设置；暂停、隐藏、外观编辑、离开庭院时停止，恢复后不会叠加循环或补播。新增加的风声与鸟鸣资源合计约 588 KB，本地离线播放，CC0 来源和处理记录见 `public/assets/cats/audio/sources.json`。

## 2.7.4 整座小院的四季

四季变化延伸到中央石板庭院：春天嫩苔与落樱、夏天绿荫、秋天暖色苔缝与落叶、冬天沿苔藓与石缝的薄霜。地面的静态季节细节在关闭飘落粒子后仍保留，空中花叶也会飘过中央。

保留原场景的高清石板纹理和设施坐标；背景只在季节、时间或分辨率改变时合成，继续使用统一坐标与渐变切换。原有猫咪、道具和存档格式不变。实际开发环境与桌面包验证见 [2.7.4 四季记录](docs/CAT-SEASONS-2.7.4.md)。

## 2.7.3 庭院音色与背向迈步

首页只保留「桌面」和「沉浸」，声音统一在「设置 → 庭院声音」中控制。开关、音量、7类试听与原有静音偏好继续保留。

猫叫、呼噜、吃食和抓板改用经过频段柔化与首尾淡化的真实录音；毛线球、小鼠和羽毛改用布料与柔软轻敲声。9个短WAV在本地离线播放，总计约272 KB，来源、CC0许可及剪辑区间保存在 `public/assets/cats/audio/`。鸟鸣与虫鸣仍为低音量、稀疏合成声。读取途中静音、暂停或离开主题，不会补播迟到的旧声音。

背向步态新增独立的远侧后腿，使用同一只猫的脚掌与毛发画稿，左右后脚交替支撑与抬起，身体不换帧。已有两条后腿的外观单独校准关节点，避免重复加腿；自定义毛色、胖瘦和昼夜光照继续作用于腿部。

## 2.7.2 庭院铺满窗口与台阶跳跃

庭院恢复等比铺满窗口，取消上下模糊填充带；背景、猫咪、道具与点击使用同一个裁切映射。较窄的窗口会正常裁去画面两侧，原画不会被拉伸。

石板地、石阶、木廊、草垫和暖石的高度边界会触发蹲伏、起跳、落地，随后继续原来的互动或回窝路线。腾空期间的新指令会在安全落地后替换旧任务；保存和切换主题不会留下悬空位置。

取消四幅整猫画稿反复混合的步态，改为固定朝向画稿上的连续四肢、头尾运动，按实际行进距离推进脚步，减少毛色与轮廓闪动。动作类型与朝向仍来自二维画稿，连续关节变形并非三维骨骼模型。验证与限制见 [2.7.2 修复记录](docs/CAT-COURTYARD-2.7.2.md)。

## 2.7.1 庭院声音

首页「声音／静音」可直接控制庭院声音；设置中增加音量百分比、真实播放状态，以及猫叫、呼噜、进食、毛线球、抓板、羽毛和玩具小鼠的试听。首次使用请开启声音，浏览器需要一次点击来允许播放。已有静音偏好保持不变。

修复点击声占用通道导致轻抚呼噜丢失的问题；各道具在猫咪实际到达互动后发出对应声音，行走和落地有低音量脚步。提高过低的默认输出，保留短促渐入渐出和峰值余量。白天偶尔鸟鸣，夜间稀疏虫鸣，冬季关闭这些环境声；没有持续白噪声。声音均为本地合成，不依赖联网下载。

暂停、编辑、隐藏和切换主题时停止当前声音及待播反馈，避免旧主题声音残留。

## 2.7.0 猫咪外观、四季与步态

猫咪编辑改为体型大小、胖瘦、耳朵大小/形态与眼睛颜色调节，提供8种性格，移除导入与自由画笔入口；原来确认保存的毛色继续保留。外观参数在缩略图、庭院和动作中一致保存。

春季换为樱花树冠并有随风花瓣，夏季绿荫、秋季金叶、冬季薄雪；日夜简化为自动、白天、黑夜，旧清晨/黄昏存档迁移为白天。夜间保留柔和月光与可关闭的萤火虫。

步态取消长时间停帧，连续衔接四相动作，增加转向缓冲、弯道减速与准确落脚。详细操作与验证见 [2.7 交付记录](docs/CAT-COURTYARD-2.7.md)。

## 2.6.0 猫咪庭院动作与场景完善

同一个程序切换锦鲤、赶海、猫咪庭院，三主题独立存档。猫咪新增16套独立动作图集：前/后向四相步态、卧睡、进食、洗脸、抓挠和扑玩，动作按真实行进距离驱动，自定义毛色跟随身体分区。

「回窝休息」现在会走过石阶、到草垫或暖石上睡觉，留在画面中。石阶、木廊、草垫、暖石、水碗与爬架下层都有实际交互位置。爬架包含走近、蹲伏、起跳、落稳和返回地面的过程；「收回收藏」另行腾出活动位置。小窗口完整显示庭院，设施和点击保持对应。

补齐波斯、异国短毛、孟加拉、阿比西尼亚4款独立外观，共12种品种外观和4种田园花色。春、秋、冬及夜景画稿与原高分辨率庭院组合，猫咪/道具接受环境光。增加限频的短喵声、呼噜与道具轻触，不循环播放噪声。

操作、实际验证、文件及限制见 [猫咪庭院交付记录](docs/CAT-COURTYARD.md)。生成来源、真实像素尺寸与压缩记录见 [美术记录](docs/cat-art-v2/README.md)。图像由内置图像生成工具制作，该工具没有提供可指定或核实的“image2.5”型号接口。

## 从源码开始

需要 **Node.js 22.12 或更新的 LTS 版本**与 pnpm。本次维护环境使用 pnpm **11.19.0**；首次安装依赖需要联网。macOS、Windows、Linux 均可先运行网页预览。

```sh
git clone https://github.com/cyberdaddyleo/yutang.git
cd yutang
# 未安装 pnpm 时：npm install -g pnpm@11.19.0
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://127.0.0.1:5188/`。开发服务固定使用 5188 端口，若启动时报端口占用，请先停止占用它的进程。网页预览可以体验三个主题，但系统桌面层与鼠标穿透需要桌面应用。

在 **Apple Silicon Mac / macOS 12 或更新版本**，安装 Xcode Command Line Tools 后可运行：

```sh
pnpm desktop          # 构建前端及原生模块，启动桌面应用
pnpm package:mac      # 构建 release/mac-arm64/浮生锦鲤池.app
```

`release/`、`dist/`、`node_modules/` 和原生编译产物不随源码提交；克隆后不会直接带有可双击的 `.app` 或工作目录启动脚本。应用构建成功后可拖到“应用程序”文件夹。Windows/Linux 的原生桌面层尚未实现；Intel Mac 构建未在本次验证，架构说明见 [桌面开发文档](electron/DESKTOP.md)。

项目包含运行所需的离线图片和声音，字体使用系统已有字体。天气与城市查询需要联网，无需自行填写 API key。仓库包含运行素材和美术原稿；构建时会排除不参与运行的猫咪原稿 PNG。请保留背景后备图与音频文件。账号、云同步及跨用户瓶信服务未接入，收藏、草稿与瓶信均保存在本机。

## 锦鲤主题操作

- 轻点池塘投食，移动鼠标会让附近锦鲤避开；空格可向池塘中央投食。
- 「四时」切换春樱、夏荷、秋叶、冬雪；自动模式按系统日期及城市半球切换。
- 「天气」切换城市、实时天气或手动晴/云/雨/雪/雷雨。雨雪、雷雨会减慢游鱼，雪天和冬季有薄冰。
- 「日夜」选择自动、白昼或夜色。晴日有蝴蝶，夏日有蜻蜓，非冬季的夜晚有萤火虫。
- 「画锦鲤」支持颜色、画笔大小、橡皮、撤销、重画、命名和放入池塘；最多保存 12 尾自绘锦鲤。切换收藏页不会丢失草稿；关闭编辑器会放弃未保存草稿。
- 「设置」调整 3–24 尾原生鱼、溪流水声、减少动态、30 帧节能模式与暂停。
- 「沉浸」隐藏界面，按 Esc 或点击右下角按钮返回；H 也可切换。

- 信件从约 68 MiB PNG 压缩到约 5 MiB WebP，保留原尺寸与透明边缘；按需加载，存档只保存内容 ID。原始 PNG 不放入游戏包。

## 2.3 更新：退潮露沙、游鱼摆尾、画一封漂流信

- 高潮保留原来的海水覆盖范围；低潮向海中退开，露出更宽的湿沙滩，岸边保留浅水过渡与浪花。新增与原构图对齐的湿沙地形，原礁石、植物和固定潮池继续保留。
- 鱼身、尾鳍和胸鳍分别运动；蟹腿交替迈步，甲壳保持稳定，停步后自然收腿。沿用原来的水彩动物素材，动作幅度按实际小尺寸调整。减少动态与暂停仍有效。
- 「漂流瓶 → 写一封信」新增画纸，提供六色画笔、三档粗细、橡皮、撤销和清空；可以写字配画，也可以只画一张小画放流。
- 抬笔保存草稿，窗口缩放不改变笔迹位置；放流记录保留原画。旧的纯文字信件继续可读。存储失败时保留当前草稿并提示重试；未成功保存的内容无法保证在退出程序后恢复。

漂流信绘画和文字均保存在本机，不发送给其他用户。每张画纸最多 160 笔、6000 个采样点，超限会提示撤销或清空，不静默截断已保存的画作。

214 项单元测试和 5 项桌面策略测试通过；正式包已验证绘画、重载、放流、动画和潮位判定。4K 常态约 60 帧，手动涨潮短时平均约 58 帧，初期仍有一次约 0.25 秒的帧调度空档，具体结果与边界见 [2.3 验证记录](docs/RELEASE-2.3.md)。

## 2.2.2 更新：手动调潮，即刻看见海水变化

## 1.3 更新：池塘随风雨流动

- 多云水面出现缓慢漂移的柔和云朵倒影。细雨的每颗雨滴到达水面后，在真实落点产生扩散涟漪。
- 手动天气的“薄雾”改为“雷雨”，有更密的雨滴、风吹草叶与偶尔远雷；减少动态时不闪光。实时天气仍准确保留真实雾天，不将雾误报为雷雨。
- 保留“治愈流水声”开关，声音现在随季节、天气、昼夜平滑调整，混合离线溪流、雨水、树叶风声与独立远雷。切换不中断水声，关闭会停止所有声音。
- 从春秋背景中移除固定漂浮叶片，替换为独立花瓣／枫叶／银杏叶：随水流漂移，偶尔从上方落下，入水产生小涟漪；鱼群经过和附近鼠标会推开浮叶。
- 原有岸边草叶和枝叶通过局部 WebGL 纹理变形随风轻摇，鼠标靠近时略微偏转；水面有轻微折射流动。WebGL 不可用或丢失时保留静态背景，鱼群仍可互动。
- 保留桌面 4K 长边、5K／6K 动态画布及此前投食加速。背景动效最高采用 4K 长边纹理层，粒子数量有上限，云影／叶片使用小纹理缓存。春秋清理后的背景由图像生成工具返回 1672×941，再重采样到 3840×2160，未宣称原生 4K 纹理细节。

本机 24 尾鱼加雷雨的 4K／5K／6K 画布实测均为 60 FPS，详见 [1.3 验证记录](docs/RELEASE-1.3.md)。

## 1.2 更新：流水、桌面超清与投喂反应

- **治愈流水声**：将随机噪声替换成真实溪流录音，57 秒循环，支持音量与淡入淡出，离线可用，默认关闭。录音来源与 CC0 许可见 [AUDIO.md](docs/AUDIO.md)。
- **桌面超清**：桌面使用独立画布预算，标准画质的长边至少 3840 像素；在 5K / 6K 显示器上保留原生像素，最大 6144×3456 等量像素。本机 16:10 桌面实际画布从 3420×2214 提高到 **3840×2486**，保持宽高比，未拉伸。窗口仍使用原生像素 / 4K 预算，节能模式保持较低分辨率。
- **投食加速**：全池锦鲤能感知鱼食，远处以最高约 3.4 倍当前季节巡游速度加速游向鱼食；转向时控制速度，靠近食物后减速，吃完恢复巡游。落食点击不再同时把鱼吓走，之后的鼠标移动仍可触发避让。
- 设置区分“窗口渲染”和“桌面渲染”，离开桌面后显示上次桌面画布尺寸。
- 本机验证 24 条鱼在 3840×2486、5120×2880、6144×3456 的测试画布上均约 60 FPS。见 [1.2 验证记录](docs/RELEASE-1.2.md)。背景文件沿用 1.1 的 4K 重采样素材；增加画布分辨率不代表背景变成原生 6K 细节。

## 4K 与流畅度（1.1 历史记录）

- 修复每条鱼每帧在大画布上执行模糊的严重性能问题：柔和鱼影预绘到一张 288×144 小纹理，运行时重复使用。移除界面对动态池塘的重复背景模糊，并使用颜色叠层处理日夜明暗。
- 标准模式按屏幕原生像素绘制，最大约 829 万像素（3840×2160 的 4K 像素预算）；不会在 Retina 的 4K 窗口意外分配 8K 画布。小窗口不强行超采样。UI 文字由系统原生分辨率呈现。
- 四季背景文件均为 **3840×2160**。背景经过 Image Gen 重绘，但生成器实际返回 1672×941，随后重采样至 4K；这是 4K 文件，并非原生生成的 4K 细节。锦鲤、涟漪、雨雪与昆虫在运行时按画布像素绘制。
- 设置面板显示真实渲染尺寸与每秒绘制帧数。标准模式上限 60 FPS，节能 / 减少动态模式上限 30 FPS；后台隐藏和暂停时停止动画。
- 本机实测 4K、24 条鱼由约 4.7 FPS 提升到约 60 FPS。四季、雨雪雾、夜景、36 条混合鱼及设置面板测试均接近 60 FPS。结果依赖设备与运行负载，详见 [性能验证记录](docs/PERFORMANCE.md)。

## 桌面模式

首页右下角「沉浸」旁点击「桌面」，或在设置中开启「桌面池塘」，池塘进入桌面图标之下、普通应用窗口之下的原生 macOS 层。鼠标穿透，不抢焦点。

- `⌘ ⇧ K`：恢复控制窗口。
- `⌘ ⇧ F`：在鼠标位置投食；鼠标在屏幕外时在池塘中央投食。
- 菜单栏锦鲤图标：恢复控制、隐藏窗口、切换桌面、投食、退出。
- 顶部空白处拖动窗口，拖动边框缩放；右上角全屏／最小化／隐藏／关闭。关闭会退出程序，隐藏可再从菜单栏恢复。
- 桌面鼠标移动无需额外权限。跨应用点击投食需要在设置中主动开启「桌面点击投食」，并由用户在 macOS「辅助功能」中授权。默认关闭；没有主动请求或授予此权限。仅监听鼠标，不监听键盘。
- 登录启动为可选设置，默认关闭。请将应用移动到长期保留的位置再开启。

本版桌面模式适配主显示器；其他显示器上的普通窗口不受影响。Windows/Linux 可运行网页界面，原生桌面层尚未实现。应用已完成本地 ad-hoc 签名，没有 Apple Developer 公证；这是本机开发交付版本。

## 天气、定位与数据

实时天气来自 [Open-Meteo](https://open-meteo.com/en/docs)，每 15 分钟刷新，无需 API key。城市搜索使用 Open-Meteo / GeoNames。首次启动通过 [ipwho.is](https://ipwhois.io/documentation) 获取城市级网络位置，不存储 IP；手动选择的城市优先并保存在本机。网络位置可能受 VPN 或服务限流影响，可随时手动搜索修正。

本次实测天气查询成功；浏览器的自动网络定位遇到提供商 HTTP 429，已验证会明确提示并回退默认武汉。桌面中的定位按钮同样使用城市级网络定位；浏览器版支持用户主动授权精确定位。不会自动弹出系统定位权限。

天气失败保留同城缓存，缓存超过 24 小时弃用并回到默认晴天。过期天气会显示“缓存”，不会冒充实时观测，缓存昼夜也不会冻结当天时间。当前节气由太阳黄经近似计算，用于 1900–2100 年氛围显示；部分节气会微调花瓣、秋叶和雪花密度，未提供 24 套独立节日动画。

设置、自绘 PNG 纹理、城市和天气缓存在本机 localStorage。网页版与桌面版各自保存；无账号、云同步或后台上传。背景资源全部随应用打包，断网仍可观鱼、绘画、切换主题。
