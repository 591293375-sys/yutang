# 浮生 · 锦鲤池 1.10

一个可以安静陪伴工作的桌面锦鲤池塘。React + Canvas 2D / WebGL + Electron，参考用户提供的东湖碧潭风格图像。

## 在另一台电脑开发

这是浮生锦鲤池 1.10 的完整源码与离线素材。可通过 GitHub 的 Code → Download ZIP 下载，或克隆本仓库。

```sh
git clone https://github.com/591293375-sys/yutang.git
cd yutang
pnpm install
pnpm dev
```

浏览器预览：http://127.0.0.1:5188/ 。macOS 桌面开发运行 `pnpm desktop`，打包运行 `pnpm package:mac`；原生构建需要 Xcode Command Line Tools。当前原生桌面池塘适配 macOS；其他系统可先运行网页，原生桌面层需要另行适配。

[跨电脑开发提示词](开发提示词.md) 已包含所有功能、修复与验收标准，可交给开发 AI 使用。本仓库不含 node_modules 和本机生成的 .app，请依照下方命令构建。

## 构建后直接使用

当前交付为 **Apple Silicon Mac / macOS 12 或更新版本**。

双击 `release/mac-arm64/浮生锦鲤池.app`。可将应用拖到“应用程序”文件夹。

- 轻点池塘投食，移动鼠标会让附近锦鲤避开；空格可向池塘中央投食。
- 「四时」切换春樱、夏荷、秋叶、冬雪；自动模式按系统日期及城市半球切换。
- 「天气」切换城市、实时天气或手动晴/云/雨/雪/雷雨。雨雪、雷雨会减慢游鱼，雪天和冬季有薄冰。
- 「日夜」选择自动、白昼或夜色。晴日有蝴蝶，夏日有蜻蜓，非冬季的夜晚有萤火虫。
- 「画锦鲤」支持颜色、画笔大小、橡皮、撤销、重画、命名和放入池塘；最多保存 12 尾自绘锦鲤。切换收藏页不会丢失草稿；关闭编辑器会放弃未保存草稿。
- 「设置」调整 3–24 尾原生鱼、溪流水声、减少动态、30 帧节能模式与暂停。
- 「沉浸」隐藏界面，按 Esc 或点击右下角按钮返回；H 也可切换。

## 1.10 更新：水域边界与窗口控制

- 「桌面」移至右下角「沉浸」旁，主工具栏恢复六项；窄屏也不会与鱼群数量重叠。
- 按四季背景的真实岸线划定水域，跟随背景居中裁切。岸石、草岸上的点击不产生鱼食；鱼食散落与漂流也不得上岸。锦鲤与乌龟留出身体宽度，提前转向，忽略隔着岸石或无法靠近的食物。更换画质、缩放窗口后仍有效。
- 池塘和绘画区域使用正常鼠标箭头。
- 桌面应用顶部提供全屏、最小化、隐藏、关闭按钮；拖动顶部空白处移动窗口，拖动边缘改变大小。保留系统窗口边框与 macOS 红黄绿按钮。
- 隐藏保留程序，可从菜单栏锦鲤图标或 ⌘ ⇧ K 恢复；「关闭程序」和系统关闭按钮彻底退出。进入桌面模式前等待全屏退出完成，恢复窗口后可以继续移动、缩放。

验证记录见 [1.10 验证记录](docs/RELEASE-1.10.md)。

## 1.9 更新：雷声跟随雷雨、鸣叫更稀疏

- 雷声音轨只在雷雨且声音开启时允许启动；晴、云、细雨、雪天都不预播。切出雷雨、静音或音量归零立即停止雷声，并取消待播。
- 防止媒体加载较慢、连续切换天气或开发热更新后，旧播放回调让雷声重新开始。
- 同一 CC0 溪流素材重新剪成 120 秒长循环，只保留一小段低频鸣叫，减少“咕咕咕”反复出现；保留连贯流水、柔化突兀峰值，不改变播放速度或音高。使用新资源版本号，避免旧缓存。
- 93 项单元／桌面测试通过；真实媒体播放验证晴／云／雨／雪无雷声音轨、雷雨有远雷、切天气与关闭声音能停止播放。

录音处理方式见 [声音说明](docs/AUDIO.md)。

## 1.8 更新：白纸绘鱼、首页桌面与可爱小乌龟

- 绘鱼从无花纹的白色鱼身开始，保留真实鱼鳞、鳍和光影；「重新绘制」同样恢复空白，已保存的锦鲤不变。
- 首页工具栏新增「桌面」，在 macOS 桌面应用中一键铺到桌面，按 ⌘ ⇧ K 或菜单栏恢复控制。浏览器入口说明桌面应用的使用方式，并可进入沉浸观鱼。
- 小乌龟重绘为浅玉色圆壳、圆头、亮眼和圆脚掌；四肢独立缓缓划水，预览和池塘使用同一套造型。各部位预绘缓存，保持低开销。
- 调整七个首页按钮在窄屏及中等宽度窗口的排布，避免溢出或遮挡数量文字。

详见 [1.8 验证记录](docs/RELEASE-1.8.md)。

## 1.7 更新：轻雨、高清桌面与柔和游姿

- 换用新的 CC0 轻雨实录，柔化敲击、低频杂声及高频，修平循环接缝，并收低雨层音量；保留偶发风声和远雷。
- 桌面背景与鱼群统一使用实际显示像素，修复原先背景仍限制 4K、在 5K／6K 桌面被再次拉伸的问题。换屏或缩放变化会自动重算，设置中可看到两层实际尺寸。
- 轻微校正背景软边，保留插画风格。原始画面细节仍受已有背景图限制，没有把放大宣称为新增真实纹理。
- 锦鲤身体由肩部向尾部逐渐摆动，头部更稳；胸鳍独立轻划，转弯逐渐建立弧度。投食加速时摆尾随之增强，恢复巡游时放缓。

86 项逻辑／桌面测试通过；满池雷雨的 4K／模拟 5K／6K 中，背景与鱼层保持相同像素尺寸，本机约 60 FPS。详见 [1.7 验证记录](docs/RELEASE-1.7.md)。

## 1.6 更新：固定岸石，全屏细雨

- 取消池底和岸边的大范围贴图位移。仅在独立的草叶／树叶区域做小幅、根部固定的风动，鼠标靠近可轻轻拨动。
- 雨幕按完整视口生成，预留四边余量，覆盖岸边、画面底部与窄屏；雨滴落在水面才出现水圈，干燥石头和植物上不画水圈。
- 紧贴上方石岸、左岸草丛及右下岸石添加独立的平行细波，沿岸缓缓扩散、渐隐。改变窗口尺寸后仍与同一处岸线对齐；结冰和减少动态时停用。
- 保留 1.5 的降噪溪流、雨声与偶发低频率阵风，不增加声音循环层。

70 项单元测试、4 项桌面策略测试及实际 Electron 渲染检查通过，满池雷雨的 4K／模拟 5K／6K 约 60 FPS。详见 [1.6 验证记录](docs/RELEASE-1.6.md)。

## 1.5 更新：风过水面，声音更安静

- 四季背景与重新处理的声音使用版本化资源地址，避免长时间打开的窗口继续保留旧贴图。秋季／春季清水底图中的固定浮叶已移除，水上落叶由独立漂移粒子呈现。
- 水面新增成组推进的细波；临岸、石边有轻微折射和沿岸水纹明暗。草叶与枝叶的风动扩大到池塘四周，干燥石块保持稳定。减少动态和结冰时抑制风吹水纹。
- 对溪流、雨水和风声录音进行频谱降噪及柔化高频，不添加白噪音声层；保留自然水流和雨滴细节。
- 风声改为偶发阵风：开启声音后 60–120 秒首次出现，每次约 4.5–7 秒并淡出，后续间隔 90–180 秒。风声峰值降低，关闭声音、音量归零或切换天气会取消当前阵风。

本机满池雷雨场景的 4K／模拟 5K／6K 约 60 FPS。详见 [1.5 验证记录](docs/RELEASE-1.5.md)。

## 1.4 更新：长出鱼鳞的自绘锦鲤与小乌龟

- 原生锦鲤有明显的大小差异；「设置 → 锦鲤整体大小」可调整至 60%–160%。
- 在「画锦鲤」绘制时选取 55%–180% 大小；已有自绘鱼可在「我的锦鲤」逐尾调节。调整保留鱼的位置、游动状态，大小与名字一起保存在本机。
- 自绘只决定鱼身的颜色与花纹，使用与原生锦鲤共用的可弯曲鱼身，加上半透明鱼鳍、鳞片、明暗、鳃和须。绘画区直接预览成鱼。原有画稿自动提取花纹并套用新鱼身，保留原始 PNG。采用本地程序化材质映射，不需要联网或图像生成服务。
- 「画锦鲤 → 小乌龟」可加入最多 4 只小乌龟，缓慢划水、短暂停留、避让鼠标，也会吃附近的鱼食。默认没有乌龟，数量会保存。
- 满池 24 尾原生鱼 + 12 尾自绘鱼 + 4 只乌龟，在雷雨与草叶动效同时开启时，本机 4K／模拟 5K／6K 画布约 60 FPS。见 [1.4 验证记录](docs/RELEASE-1.4.md)。

## 1.3 更新：池塘随风雨流动

- 多云水面出现缓慢漂移的柔和云朵倒影。细雨的每颗雨滴到达水面后，在真实落点产生扩散涟漪。
- 手动天气的“薄雾”改为“雷雨”，有更密的雨滴、风吹草叶与偶尔远雷；减少动态时不闪光。实时天气仍准确保留真实雾天，不将雾误报为雷雨。
- 保留“治愈流水声”开关，声音现在随季节、天气、昼夜平滑调整，混合离线溪流、雨水、树叶风声与独立远雷。切换不中断水声，关闭会停止所有声音。
- 从春秋背景中移除固定漂浮叶片，替换为独立花瓣／枫叶／银杏叶：随水流漂移，偶尔从上方落下，入水产生小涟漪；鱼群经过和附近鼠标会推开浮叶。
- 原有岸边草叶和枝叶通过局部 WebGL 纹理变形随风轻摇，鼠标靠近时略微偏转；水面有轻微折射流动。WebGL 不可用或丢失时保留静态背景，鱼群仍可互动。
- 保留桌面 4K 长边、5K／6K 动态画布及此前投食加速。背景动效最高采用 4K 长边纹理层，粒子数量有上限，云影／叶片使用小纹理缓存。春秋清理后的背景由图像生成工具返回 1672×941，再重采样到 3840×2160，未宣称原生 4K 纹理细节。

本机 24 尾鱼加雷雨的 4K／5K／6K 画布实测均为 60 FPS，详见 [1.3 验证记录](docs/RELEASE-1.3.md)。

## 1.2 更新：流水、桌面超清与投喂反应

- **治愈流水声**：将随机噪声替换成真实溪流录音，57 秒循环，支持音量与淡入淡出，离线可用，默认关闭。录音来源与 CC0 许可见 [AUDIO.md](docs/AUDIO.md)。
- **桌面超清**：桌面使用独立画布预算，标准画质的长边至少 3840 像素；在 5K / 6K 显示器上保留原生像素，最大 6144×3456 等量像素。本机 16:10 桌面实际画布从 3420×2214 提高到 **3840×2486**，保持宽高比，未拉伸。窗口仍使用原生像素 / 4K 预算，节能模式保持较低分辨率。
- **投食加速**：全池锦鲤能感知鱼食，远处以最高约 3.4 倍当前季节巡游速度加速游向鱼食；转向时控制速度，靠近食物后减速，吃完恢复巡游。落食点击不再同时把鱼吓走，之后的鼠标移动仍可触发避让。
- 设置区分“窗口渲染”和“桌面渲染”，离开桌面后显示上次桌面画布尺寸。
- 本机验证 24 条鱼在 3840×2486、5120×2880、6144×3456 的测试画布上均约 60 FPS。见 [1.2 验证记录](docs/RELEASE-1.2.md)。背景文件沿用 1.1 的 4K 重采样素材；增加画布分辨率不代表背景变成原生 6K 细节。

## 4K 与流畅度（1.1 历史记录）

- 修复每条鱼每帧在大画布上执行模糊的严重性能问题：柔和鱼影预绘到一张 288×144 小纹理，运行时重复使用。移除界面对动态池塘的重复背景模糊，并使用颜色叠层处理日夜明暗。
- 标准模式按屏幕原生像素绘制，最大约 829 万像素（3840×2160 的 4K 像素预算）；不会在 Retina 的 4K 窗口意外分配 8K 画布。小窗口不强行超采样。UI 文字由系统原生分辨率呈现。
- 四季背景文件均为 **3840×2160**。背景经过 Image Gen 重绘，但生成器实际返回 1672×941，随后重采样至 4K；这是 4K 文件，并非原生生成的 4K 细节。锦鲤、涟漪、雨雪与昆虫在运行时按画布像素绘制。
- 设置面板显示真实渲染尺寸与每秒绘制帧数。标准模式上限 60 FPS，节能 / 减少动态模式上限 30 FPS；后台隐藏和暂停时停止动画。
- 本机实测 4K、24 条鱼由约 4.7 FPS 提升到约 60 FPS。四季、雨雪雾、夜景、36 条混合鱼及设置面板测试均接近 60 FPS。结果依赖设备与运行负载，详见 [性能验证记录](docs/PERFORMANCE.md)。

## 桌面模式

首页右下角「沉浸」旁点击「桌面」，或在设置中开启「桌面池塘」，池塘进入桌面图标之下、普通应用窗口之下的原生 macOS 层。鼠标穿透，不抢焦点。

- `⌘ ⇧ K`：恢复控制窗口。
- `⌘ ⇧ F`：在鼠标位置投食；鼠标在屏幕外时在池塘中央投食。
- 菜单栏锦鲤图标：恢复控制、隐藏窗口、切换桌面、投食、退出。
- 顶部空白处拖动窗口，拖动边框缩放；右上角全屏／最小化／隐藏／关闭。关闭会退出程序，隐藏可再从菜单栏恢复。
- 桌面鼠标移动无需额外权限。跨应用点击投食需要在设置中主动开启「桌面点击投食」，并由用户在 macOS「辅助功能」中授权。默认关闭；没有主动请求或授予此权限。仅监听鼠标，不监听键盘。
- 登录启动为可选设置，默认关闭。请将应用移动到长期保留的位置再开启。

本版桌面模式适配主显示器；其他显示器上的普通窗口不受影响。Windows/Linux 可运行网页界面，原生桌面层尚未实现。应用已完成本地 ad-hoc 签名，没有 Apple Developer 公证；这是本机开发交付版本。

## 天气、定位与数据

实时天气来自 [Open-Meteo](https://open-meteo.com/en/docs)，每 15 分钟刷新，无需 API key。城市搜索使用 Open-Meteo / GeoNames。首次启动通过 [ipwho.is](https://ipwhois.io/documentation) 获取城市级网络位置，不存储 IP；手动选择的城市优先并保存在本机。网络位置可能受 VPN 或服务限流影响，可随时手动搜索修正。

本次实测天气查询成功；浏览器的自动网络定位遇到提供商 HTTP 429，已验证会明确提示并回退默认武汉。桌面中的定位按钮同样使用城市级网络定位；浏览器版支持用户主动授权精确定位。不会自动弹出系统定位权限。

天气失败保留同城缓存，缓存超过 24 小时弃用并回到默认晴天。过期天气会显示“缓存”，不会冒充实时观测，缓存昼夜也不会冻结当天时间。当前节气由太阳黄经近似计算，用于 1900–2100 年氛围显示；部分节气会微调花瓣、秋叶和雪花密度，未提供 24 套独立节日动画。

设置、自绘 PNG 纹理、城市和天气缓存在本机 localStorage。网页版与桌面版各自保存；无账号、云同步或后台上传。背景资源全部随应用打包，断网仍可观鱼、绘画、切换主题。

## 验证记录

- 单元测试覆盖季节/节气/天气映射、请求中止与超时、缓存校验、鱼群避让与吃食、数量上限和暂停。
- 在 Codex 内置浏览器验证 1280×720、390×844、1672×941；检查四季、天气、城市查询、自绘→撤销→保存→重载→移走、沉浸和设置。
- 修复了画稿切换页丢失和空格抢占按钮的问题，并针对原复现步骤验证。
- 原生打包应用实测窗口/桌面切换、真实桌面层、鼠标坐标映射、界面恢复、持续动画、安全 preload、无 Node 权限和本地签名。
- 没有替用户开启全局点击系统权限、登录启动；这两个系统授权流程由用户自行启用。
- 四季背景是在参考图基础上生成的独立素材；锦鲤使用可变形的 Canvas 绘制与纹理，避免静态鱼图假装可互动。

## 文件结构

`src/engine/` 鱼群模拟与绘制；`src/components/` 交互界面与自绘；`src/hooks/` 天气/声音；`src/lib/` 环境与数据校验；`public/assets/` 四季背景；`electron/` 桌面壳与原生模块；`tests/` 单元测试。
