# 财源广进扩图修复

2026-10-01。替换此前镜像并拉伸窄边缘的做法，避免柱子折歪、屋檐翻转和桌布变形。

内置 image_gen 编辑工具分别补绘上下和两侧环境；工具不暴露可选的模型版本号。最终 PNG 原稿、完整提示词和来源见 `source-art/caiyuan/outpaint-provenance.json`。运行时两张 WebP 合计约 1.1 MB。

`src/themes/caiyuan/backdrop.js` 用单一等比缩放绘制扩图，再覆盖未修改的中央原图；AI 生成的中央人物和文字不会替换原画。`renderer.js` 按窗口比例加载对应扩图，仍缓存静态背景，未新增动画循环。摆件、香烟、金蟾、命中检测和存档坐标全部沿用现有映射。

实际预览检查了 1357×911、1920×1080、1440×900（DPR 2）、2560×1080、900×900。中央原图 3381 个采样点在每个窗口中均与原始绘制像素完全一致；各边都有完整纹理。灯具点击、长按水果拖动、日夜、窗口缩放后布局保留通过，无页面异常。截图与测试报告在工作区 `work/caiyuan-outpaint/`。

对应提交只调整财源广进的背景绘制、两张运行素材、扩图原稿及说明；没有修改其他主题或用户存档。扩图仍是静态手绘环境，并非三维建筑；极端窄长或超过已补绘范围的窗口不在本次验证范围。
