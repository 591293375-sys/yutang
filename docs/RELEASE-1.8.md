# 1.8 验证记录

日期：2026-09-27。测试使用隔离的 Electron 用户目录，不覆盖用户的锦鲤、数量、城市或声音偏好。

## 改动

- 新建和「重新绘制」都从全白底色纹理开始，不再预画橙色花纹；保留鱼身结构、鳞片、鳍和光影。旧收藏不变。
- 首页工具栏增加「桌面」，桌面应用直接进入原生桌面层；浏览器展示桌面应用使用说明和沉浸入口。仍用 ⌘ ⇧ K／菜单栏恢复控制，不自动开启全局点击权限。
- 小乌龟重绘：圆玉色龟壳、明亮眼睛、柔和脸颊和圆脚掌。保留原有游动和吃食，龟壳／头／脚缓存为独立精灵，预览与池塘共用。
- 七个工具按钮在中等及窄窗口自适应，避免与鱼群数量、沉浸入口重叠。390px 下所有标签均为单行。

## 验证

- 86 项现有逻辑与桌面策略测试通过；生产构建通过。
- 绘鱼初始无红色斑纹；画笔绘制、撤销、重画、标签间保留草稿通过。保存的白色锦鲤全部 512×128 纹理像素均为底色，无任何默认花纹。重新打开编辑器仍为空白。
- 小乌龟预览随时间划水，添加入池与 4 只数量上限通过；目视检查了预览与池塘造型。
- 首页按钮触发真实桌面层：池塘持续游动、位于桌面、鼠标穿透、恢复控制正常；全局点击权限保持关闭。
- 无原生桥接的独立浏览器窗口正确展示使用说明，沉浸／返回可用。
- 1357、1101、1082、1000、950、580、390 像素宽度下，七个工具和沉浸按钮均在视口内，且不与数量文字重叠；页面无运行时错误。
- 打包版 1.8.0 在 Apple Silicon Mac 上加载成功；离线四季背景与四段声音均可解码，原生安全设置保留，深度签名校验通过。
