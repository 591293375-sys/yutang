# 2.2：沙滩画画与漂流瓶

本版在原有赶海主题上增量修改，继续使用同一个程序、窗口、设置与存档。锦鲤主题和已有赶海收藏不重置。

## 本次改动

1. **水面与岸线**：使用共享岸线的距离场生成连续浅深水色，保留水下沙纹，去掉重复铺开的水纹。两组错开的细碎浪花沿弯曲岸线推进、铺开和退回，浅水边缘透明渐变。光学色层缓存后按双线性插值绘制，动态画布仍按高分辨率输出。
2. **沙滩绘画**：观察模式下，在没有动物的沙滩长按左键并拖动即可画画。画痕采用世界坐标，缩放后位置保持对齐；海浪覆盖或涨潮淹没的位置逐段冲淡，退潮后不会复原。短点动物、藏沙发现、捕捉模式仍沿用原操作。切换主题或关闭后不保存临时沙画。
3. **潮汐图标**：改为日光与水波图标，潮汐控件使用普通箭头光标。
4. **漂流瓶**：底部「声音」入口改为「漂流瓶」。海中偶尔漂来小瓶，轻点可以拾起、读信、收藏；也可以写一封最多600字的信并放回海里。草稿、收到的信和放流记录保存在本机。海浪声音开关与音量继续放在「设置」。

漂流瓶目前是**本机离线玩法**。来信为内置原创海边短笺，用户写的信不会发送给其他真实用户。首次到访约2–4分钟，后续到访间隔约8–15分钟；离线期间不累计瓶子或奖励。海中最多1只来信瓶与2只放流瓶；收藏和放流记录各最多100封。容量已满或保存失败时保留原状态，不吞信、不重复计数。

完整潮汐检查还修复了左下岸带螃蟹被涨潮困住的问题：螃蟹提前沿可行的岸边路径绕过礁石，移动仍逐帧检查生境与身体范围。没有通过放宽生境限制或瞬移处理。

## 运行与检查

- 打开上一级 `打开摸鱼桌面.command`，或 `release/mac-arm64/浮生锦鲤池.app`。旧桌面程序如果仍开着，退出后重新打开。
- 源码压缩包为上一级 `摸鱼桌面-2.2-完整源码.zip`。解压后按 README 安装依赖。
- 基础检查：`pnpm test`、`pnpm test:desktop`、`pnpm build`。
- 正式包交互检查：`node electron/coast-smoke.cjs --packaged`、`node electron/coast-bottle-smoke.cjs --packaged`、`node electron/coast-sand-smoke.cjs --packaged`、`node electron/packaged-smoke.cjs`。所有自动化使用独立临时档案，不改日常存档。

## 素材与范围

本次没有新增必需素材，漂流瓶和沙画由程序绘制。海岸低潮底图仍为1672×941；4K输出画布不等于底图拥有原生4K细节。可替换底图的尺寸和透明要求见 [COAST-ASSETS.md](COAST-ASSETS.md)。本次桌面构建目标为 macOS arm64，本地 ad-hoc 签名。
