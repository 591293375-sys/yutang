# 猫咪庭院：Electron 隔离存档 UI 验证

2026-09-30 实际运行 `electron/cat-courtyard-smoke.cjs`：开发模式 PASS（16 组），最终 **2.5.0 macOS 发行版 PASS（17 组）**，两种模式页面错误和猫咪资源失败均为 0。测试新建临时 Electron 用户目录，确认目录与运行时 `app.getPath('userData')` 一致，退出删除；没有读取或写入日常应用存档。

## 运行

在项目目录运行：

```sh
node electron/cat-courtyard-smoke.cjs
# 桌面应用打包后，可以对发行版重复同一组流程：
node electron/cat-courtyard-smoke.cjs --packaged
```

开发模式默认读取 `http://127.0.0.1:5188/`，可通过 `VITE_DEV_SERVER_URL` 覆盖。发行版路径可用 `POND_TEST_EXECUTABLE` 覆盖。`--packaged` 使用本地发行包，不读取开发服务器。
