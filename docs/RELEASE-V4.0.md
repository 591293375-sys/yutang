# v4.0 · 摸鱼桌面：四处风景

应用版本：**4.0.0**。日期：2026-10-01。

## 本次内容

- 同一个程序内切换锦鲤池、赶海、猫咪庭院、财源广进；沿用原来的主题入口、天气、设置与桌面窗口行为。
- 新增财源广进：保留五位财神和完整匾额的原画、默认供桌、三炷香及计时/熄香/离线燃尽、莲灯独立开关、整盘供品、添茶、60 字简洁心愿牌、静心、日夜与本地配乐。
- 供桌物件可直接按住左键拖动，支持添加、缩放、收纳、撤销、清空与恢复默认；保留已有布局及主动清空的桌面。
- 金蟾自主眨眼、活动和打盹，投铜钱后拾取、抱钱、送入聚宝盆；灯笼流苏、前景薄云、浮尘、灯火与流动香烟保持柔和动态。修复金蟾跳跃切换闪动。
- 按反馈移除整理、祝福笺，以及灯笼/微风独立开关和动效强度选择；旧数据保留兼容，减少动态仍可设置。
- 财源广进场景用 AI 扩图补齐屋檐、桌前和侧窗以消除留边，完整画面与交互坐标保持不变，不裁掉人物和匾额。
- 猫咪改用完整原画做有限幅度的连续步态变形，保留四肢轮廓与脚掌；延续真实台阶跳跃、树下遮挡和就餐对位。天气复用共用显示，爬架保持在画面中。
- 猫咪新增轻缓无人声配乐「晴窗小憩」，独立开关/音量，服从总声音、暂停与可见性；主题切换释放旧音源。两个新主题的微风使用低音量的自然录音处理版本。

## 数据与素材

原有主题存储键、应用标识和用户存档保持不变，财源广进使用独立命名空间。代码仓库包含完整源码、本地运行素材、高清母版、音频来源说明、测试与原生 macOS 代码。个人浏览器/应用存档、依赖目录、临时输出和打包缓存不上传。

音乐及图片不统一声明为 CC0；用户提供图片、生成配乐和录音素材的说明分别保留在相应目录。现有旧版本文档仍为历史记录，以本说明和当前界面为准。

## 运行与限制

按根目录 README 执行 `pnpm install --frozen-lockfile`、`pnpm dev`；桌面运行 `pnpm desktop`，Apple Silicon Mac 打包运行 `pnpm package:mac`。

本次 GitHub 提供源码与素材，不附编译安装包。macOS 使用本地 ad-hoc 签名，未进行 Apple 公证。二维猫咪与金蟾仍基于现有静态画稿和程序动画，并非完整八方向三维模型；扩图和中央原画均等比绘制，未再使用镜像或拉伸；当前验证范围为正方形窗口到 21:9 超宽窗口。
