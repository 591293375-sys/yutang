# 猫咪步态与台阶修复 · v4.1

本次只修改猫咪绘制层，保持猫原画、各款毛色、体型设置、庭院 UI、设施位置、路径、任务与存档格式。

## 修复

- 背向原画中缺少的远侧前腿和后腿成为独立绘制层，使用同一只猫原画中的腿、毛边和完整脚掌。四脚复用现有四拍支撑/摆动周期，左右交替；躯干保持原画轮廓，不把猫身擦除后重新画成柱状腿，不轮换整猫贴图。
- 已经画有远侧腿的品种直接驱动原画相应部位，不重复添加第五、第六条腿。远侧腿在躯干后方，重叠时自然被身体遮挡。
- 跨越石阶、木廊边缘和猫爬架时使用简短的原地淡出、在安全落脚点淡入。移除了这类转换的站立贴图俯仰、拉伸和空中平移表现。平地和很低的床沿继续普通走路，不触发淡化。
- 透明度同时作用于猫和接触影；完全淡出的猫暂不参与点击命中，落稳后恢复。原有路径、预约、在途新指令、暂停与持久化安全落点策略继续复用。

## 文件

- `src/themes/cats/painted-gait.js`：背向远侧腿原画图层、锚点和四脚绘制。
- `src/themes/cats/traversal.js`：只负责视觉的支持面端点/透明度计算。
- `src/themes/cats/renderer.js`：支持点淡入淡出、阴影和命中同步。
- `tests/cats-traversal-presentation.test.js`：端点、透明度连续性、低沿不闪、存档落点与左右脚交替回归。

## 验证记录

2026-10-03 在隔离 Electron 配置中实际加载项目。16 款猫分别导出前向/背向 4 个步态相位；另录制连续 Canvas 步态及 24 秒场景验证，覆盖地面→石阶→木廊、木廊→石阶→地面及爬架落稳。过程中无 JavaScript 异常；中间阶段不再显示横穿台阶立面的站立猫。

猫咪专属单元测试共 172 项通过，包含原有攀爬、台阶预约/恢复、喂食、定制、声音和环境回归。完整发布构建、真实 UI 路由和其他主题验收由 v4.1 发布报告汇总。
