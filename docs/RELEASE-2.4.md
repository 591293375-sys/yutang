# 2.4.0 漂流瓶交付记录

## 实际改动

- 同一张 720×480 逻辑信纸叠加文字与透明笔迹，可切换打字、画笔、橡皮。文字和笔迹一起缩放，放流记录用同一组件阅读。草稿、旧文字和旧绘画存档不迁移、不清空；擦除与清空笔迹保留文字。
- 放流成功后收起面板，播放约 1.3 秒弧线抛投、转动和入水水花，再接正常漂流。减少动态时只淡入与轻涟漪；暂停、隐藏、失焦、主题卸载清除瞬态，不写入存档。
- 来瓶与自己放出的瓶子都可点。自己的瓶子打开对应放流记录，不重复收藏。绘制与命中共用浮动、旋转姿态，最小点击区域 44 CSS 像素，容许 14 像素轻微晃动；面板遮挡时不会点穿到场景。发送按钮连续双击也不会误开底层控件。
- 接入用户提供的 29 张信纸，以稳定 contentId 随机抽取未收藏内容。已拾取的内容单独记录，重启后不重复。没有拾到的信不计已读；全部收齐后停止来信。旧的文字收藏继续保留。
- 信件 PNG 68.06 MiB → WebP 5.02 MiB（减少 92.63%），不缩放、透明通道逐像素相同；页面按需读取图片，存档只写 ID 与元数据。素材来源和逐张大小见 [COAST-LETTERS.md](COAST-LETTERS.md)。

## 验证方式

测试只使用独立临时 Electron 用户档案，没有覆盖日常存档。到达测试通过存档夹具将一只正常生成的瓶子放在其合法路线终点，未修改生产版来信频率。动画验证使用真实 requestAnimationFrame；自动截图读取当时实际画布，没有暂停或加速渲染。

- 228 项全套单元测试通过；追加的 3 项关闭面板双击保护测试通过，共 231 项。5 项原生桌面策略测试通过。
- 29 封完整随机收集，每次拾取后重新加载，全部内容唯一；收齐后停止来信。另测保存失败回滚、已读记录恢复与旧文字兼容。
- 开发版和 macOS arm64 2.4.0 正式包验证了文字/笔迹共用一张纸、绘画/橡皮/撤销、重载与窗口缩放、纯图画放流、600 字长信、连续发送/拾取和存储失败恢复。
- 正式包真实抛投约 1.35 秒后结束，只启动一次；期间有空中和入水帧，存档中没有抛投字段。落水后可点自己的瓶子阅读原信。
- 800×600 与 390×844 两种窗口，各测观察/捕捉模式；8 或 12 像素轻微拖动均正常拾取，面板遮挡不会透传，重载收藏保持不变。浏览器控制台无错误。
- 原锦鲤存档内容保持不变；本次没有修改鱼类行为、潮汐、水域、音效或桌面窗口实现。
- macOS arm64 正式包构建与 `codesign --verify --deep --strict` 通过。本次没有测试 Windows、Intel Mac 或其他真实显示器。

## 复现命令

```sh
pnpm test
pnpm test:desktop
pnpm package:mac
node electron/coast-bottle-smoke.cjs --packaged
node electron/coast-letter-drawing-smoke.cjs --packaged
node electron/coast-bottle-interaction-2.4-smoke.cjs --packaged
codesign --verify --deep --strict release/mac-arm64/浮生锦鲤池.app
```

不带 `--packaged` 时，GUI 检查使用 `http://127.0.0.1:5188/` 的开发服务器。没有等待真实的首次 2–4 分钟或之后 8–15 分钟随机来信时段；时间和离线逻辑使用模型测试覆盖。漂流信仍是本机离线功能，不与其他用户交换。
