### 坐标与涂色契约

- `src/themes/cats/catalog.js` 为每张独立图登记品种、毛色、毛长、脸型、耳朵、尾巴、场景比例、基础速度、动作资源接口。
- 离线只裁切全透明边界、补 8px 透明安全边、方形居中和缩放压缩，不重画猫咪。`asset-manifest.json` 保存来源文件、原始 alpha 边界、方形尺寸和偏移。
- 最终猫纹理与缩略图使用同一方形构图。涂色区域、眼鼻口保护椭圆、落脚点和身体对称轴都是**最终方图中的 0—1 坐标**，不依赖编辑器缩放、平移或屏幕分辨率。
- 身体对称轴沿斜俯视猫的头到躯干方向，不能用屏幕水平方向直接镜像笔画。
- 头部 / 身体 / 尾巴 / 四肢矩形用于辅助选区，仍需与猫咪 alpha 轮廓相交；它们不是可直接拿来旋转的分层部件。
- 眼鼻口保护区逐图检查过，不能把它们当作高精度语义分割；后续动作图需提供对应保护遮罩和 UV 映射。
- 原始单图阶段只有 `actions.idle` 对应素材。后续动作 atlas 由独立 manifest 接入；单站姿图本身仍不能当作真实行走、坐卧或进食序列。新增动作不得改变 canonical 外观坐标契约。

## 已补动作与可选的高精度升级规格

16预设均已有独立16姿态atlas，共256帧，含前后向四相步态、卧睡、进食、梳理、抓挠和扑玩。完整帧定位、透明轮廓、毛色与保存恢复检查已通过，合计8.09MiB。下表是增加方向和过渡帧的可选升级规格，不是当前运行的素材阻塞。

| 动作 | 推荐帧数 / 节奏 | 用途 |
| --- | --- | --- |
| 呼吸待机、看向目标 | 4—6 帧 / 6—8 fps | 安静站立、耳朵和视线细微变化 |
| 行走 | 每方向 8—12 帧 / 10—12 fps | 前后斜向至少 4 方向，接触脚步自然交替 |
| 坐下、起身、趴卧、睡眠 | 转换 6—8 帧 + 循环 4 帧 | 自主休息、夜间入睡 |
| 低头嗅闻、进食、舔嘴 | 6—10 帧 | 食盆互动 |
| 舔爪、洗脸、梳毛 | 8—12 帧 | 梳理与进食后的恢复 |
| 抬爪、轻拍、扑抓 | 6—10 帧 | 毛线球、逗猫棒、小鼠 |
| 伸展、抓挠、伸懒腰 | 8—12 帧 | 猫抓板 |
| 眯眼、蹭手 | 4—6 帧 | 轻抚 |

每帧透明 PNG，建议 1024 × 1024 同画布、同落脚锚点；动作可做 sprite atlas，但不要把多帧直接画在当前单图内。没有背景和固定投影，柔和接触阴影由场景统一渲染。不得旋转整张站姿猫图冒充不同朝向。

为了让已保存的涂色跨动作稳定，需要同步交付以下一种方案：

1. 每帧到规范身体纹理的 UV / 重映射图、同尺寸轮廓与五官保护 mask，以及脚底锚点；或
2. 头、躯干、尾巴、四肢的透明分层和骨骼绑定 / 网格 UV，局部关节避免毛边。

新增动作时可从 `actions` 接入，并保留当前 canonical appearance 版本，不应把编辑器屏幕坐标复制到每一帧。

## 已接合成音效与可选实录替换

目前猫咪目录没有音频。若使用程序合成的轻提示或呼噜音色，应标为合成反馈，不能称为已获得真实猫咪录音。

建议补充经过授权的素材：轻柔短猫叫 3—5 条（0.4—1.5 秒）、短呼噜 2—3 条（2—4 秒）、柔软石板脚步 3 条、毛线 / 小鼠轻碰各 2 条、抓板轻挠 2 条（0.3—0.8 秒）。无混响、无背景人声或持续底噪，44.1 / 48 kHz 单声道 WAV 原始文件；运行包压缩为 Opus / Ogg 或 MP3，音量统一并限频。安静庭院环境声如补充，应使用可停留较长时间而不刺耳的自然录音，避免持续白噪音。
