# V3.0 · 摸鱼桌面：锦鲤、赶海与猫咪庭院

应用与源码版本统一为 `3.0.0`，GitHub 发布标签为 `V3.0`。在已有锦鲤池、赶海主题上加入猫咪庭院，三个主题共用界面、桌面窗口、通用设置，并分别保存本机收藏和场景状态。

## 猫咪庭院

- 提供 12 种品种外观和 4 种田园花色，默认布偶、英短蓝猫、橘白猫；同场最多 12 只，收藏可单独管理。
- 可调整大小、胖瘦、耳朵、眼睛颜色、名字和性格；已有绘制毛色继续兼容。
- 食物、毛线球、猫抓板、逗猫棒、玩具小鼠与轻抚使用「先选择道具，再点击猫或地面」的操作方式。
- 四肢采用共用的二维关节步态，按实际移动距离落脚；平地不弹跳，石阶、木廊、草垫等高低处保留蹲伏、起跳和落稳。
- 「回窝休息」会让猫咪前往草垫或暖石睡觉；花坛、设施和可行走区域有独立空间判定。
- 四季变化覆盖庭院中央与边缘，春季樱花、夏季绿荫、秋季落叶、冬季薄霜；日夜可跟随本机时间或手动选择。
- 树冠局部遮挡、脚底接触影、树荫和夜间明暗共同呈现猫咪在场景中的位置；夜晚可开启萤火虫。
- 庭院声音包含柔和持续微风、低频率鸟鸣和猫叫，以及限频的道具互动声音，沿用静音与音量设置。

## 进食对齐修复

食盆不再使用普通道具的统一靠近距离。按各品种进食姿态的嘴部位置及当前体型反算停靠点，让猫咪先走到位、面向猫粮，再低头进食。食盆固定在投放位置；两只猫使用分别计算的就餐位置，避免背对食盆或对着旁边石板吃。

## 存档与启动

保持应用 ID、用户数据位置、三个主题存档命名空间和已有收藏兼容。无需清空存档；旧版桌面进程退出后，再打开新构建的应用。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

网页预览：`http://127.0.0.1:5188/`。Apple Silicon Mac 安装 Xcode Command Line Tools 后可使用 `pnpm package:mac` 构建 `release/mac-arm64/浮生锦鲤池.app`。

源代码包含离线运行图片、声音、素材来源说明和美术原稿；`node_modules`、构建输出、临时测试档案、本机日志及配置文件不纳入源码发布。

## 本次验证

407 项逻辑测试与 5 项桌面策略测试通过。开发版检查全部 16 种猫及大小、双猫组合，共 19 个场景；macOS arm64 3.0.0 正式包的 6 个代表场景、三主题切换和猫咪状态恢复通过，进食期间嘴部位于猫粮范围，食盆与脚点保持稳定。构建及本地签名校验通过。完整记录和可复现命令见 [喂食验证](CAT-FEEDING-3.0.md)。

## 范围与限制

猫咪仍是手绘素材上的二维关节动画，方向使用前后画稿与左右镜像。Windows/Linux 可运行网页界面，原生桌面层尚未实现；本次桌面构建面向 macOS arm64，使用本地 ad-hoc 签名，未进行 Apple Developer 公证。天气查询需要联网，收藏、瓶中信和猫咪设计均在本机保存。

历史四足步态与性能采样说明见 [2.8.0 记录](CAT-LOCOMOTION-2.8.md)，猫咪功能及素材说明见 [庭院记录](CAT-COURTYARD.md)。
