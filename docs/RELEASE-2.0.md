# 2.0：同一程序中的锦鲤与赶海

交付日期：2026-09-29。沿用 React 19、Canvas 2D / WebGL、Electron 37；没有增加运行时依赖。桌面交付为 macOS 12+ / Apple Silicon。

## 实际改动

- `src/themes/registry.js` 是最小主题注册表，首页左上角主题名打开原有风格面板。App、天气、设置和桌面窗口常驻；各主题场景独立挂载与销毁。
- `src/themes/coast/` 分为目录、统一空间几何、潮汐时钟、实体规则、存储校验和渲染。使用 1600 × 900 世界坐标及 cover 映射；同一海岸曲线驱动海水、点击、生境和碰撞。
- 潮汐时长集中在 `TIDE_DURATIONS`：600 / 300 / 600 / 300 秒。涨退潮余弦缓动，阶段连续，海水真实覆盖/露出沙滩。低潮潮池保水，礁石前景遮挡，水下贝壳随深度渐隐。
- 接入提供的 17 种外观，包含蟹类、寄居蟹、鱼、虾、章鱼、海星、贝壳与海螺。鱼从永久海域边缘分批进入，浅水目标按占用间距分散，避免访客挤在同一点；退潮时回撤；少量现有鱼虾留在近岸湿沙，至多 3 只/周期。
- 观察、捕捉、捡贝、搁浅救助、小桶、单只/同种/全部放生、图鉴已接入共用 UI。小桶 12 位，活体总量上限 52（含桶内），贝壳实例上限 24；操作同步占用实体，过渡动画不重复记奖。
- `mofish-coast-v1` 保存独立赶海状态，`mofish-theme` 保存最后主题。旧锦鲤存储键、格式与桌面 app ID 保留。兼容无新键的历史存档，默认仍是锦鲤池。
- 切换、关闭、睡眠和隐藏窗口后，按持久化潮汐起点与真实经过时间恢复。忽略错过的周期，不补演奖励；调试时钟不会把未来周期的入场账本写进真实时间。
- 实际操作前刷新潮位并重新命中，防止恢复后的旧画面把已经回水的鱼再次救助，或捕捉错位实体。
- 新增离线 90 秒实录海浪，与原溪流、轻雨、偶发风和雷共用音频基础能力。主题切换停止旧主题声层与待播回调；雷声仅在雷雨。
- 调试面板仅开发环境可见：暂停、手动潮位、阶段跳转、60 倍速与空间区域轮廓。生产包不暴露这些控件。

## 运行与截图

- 上一级 `打开摸鱼桌面.command` 启动同一个已打包应用，原 `打开锦鲤池.command` 仍有效。
- 应用包仍位于 `release/mac-arm64/浮生锦鲤池.app`，保留旧名称及 app ID 是为了沿用原本的系统用户数据和启动入口。
- 网页开发：`pnpm install`、`pnpm dev`，打开 `http://127.0.0.1:5188/`。
- 自动检查：`pnpm test`、`pnpm test:desktop`、`pnpm test:coast`（需 dev 正在运行）、`node electron/coast-smoke.cjs --packaged`、`node electron/packaged-smoke.cjs`。
- 正式窗口与桌面截图在项目上一级的 `赶海主题-窗口预览.png`、`赶海主题-桌面预览.png`。桌面截图是屏幕的 3420 × 2214 像素，应用内部画布是 3840 × 2486，两者含义不同。另有 `赶海主题-高潮.png`、`赶海主题-低潮.png` 可对比水域变化。高低潮交付截图来自同一不中断的自然 60 倍加速周期，等待对应阶段文字刷新后拍摄；没有中途手动跳转。

## 素材条件与未验证范围

- 用户原始海岸是 7680 × 4320 合成图，不能直接独立移动潮线；本次以它生成了清除固定动物和浪花的低潮地形，再用运行时纹理、曲线遮罩、湿沙和前景分层完成真实潮汐。没有用缩放整张背景伪装潮位。
- **生成的干净地形实际为 1672 × 941，尚非原生 4K 地形细节**。高分辨率画布已实现，仍可用同构图的 3840 × 2160/7680 × 4320 干净低潮图进一步提升大屏清晰度。素材尺寸与透明要求见 [COAST-ASSETS.md](COAST-ASSETS.md)。
- 用户未提供海胆、海参、弹涂鱼，因此这三种未接入。现有动态层与第一版玩法不依赖它们。
- 声音做了信号与实际媒体播放检查，未把这些检查当作人工听感评价。来源及 CC0 许可见 [COAST-AUDIO.md](COAST-AUDIO.md)。
- 跨应用全局点击权限保持用户原设置，未替用户开启辅助功能授权；原生穿透、坐标策略、窗口内点击与桌面恢复已验证。没有实测新开启系统权限的全局点击或登录启动流程。
- Windows/Linux 的原生桌面层未实现，沿用之前的 macOS 适配范围；网页可独立运行。未新增云账号、云同步或现实潮汐接口。
