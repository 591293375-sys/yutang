# 2.1：藏沙发现、水下游姿与浪涌

本版基于原项目增量修改，保留主界面、应用 ID、存储路径、锦鲤存档与赶海收藏。未更换技术栈。

## 已完成的六项改动

1. 观察模式在场景内使用手形光标，按下时握起；捕捉模式使用可离线加载的小钳子 SVG。控件与锦鲤光标不受影响。
2. 逐种校准动物原图朝向，按水深调整鱼的大小、明暗与水色，水纹绘制在鱼上方。固定潮池与海域共用联合裁剪，低潮潮池中的虾不会消失。
3. 部分蟹、寄居蟹与贝壳藏在浅沙痕下，轻点 2–3 次逐步露出；石缝小鱼轻点一次游出。保留实例 ID，揭开时不捕捉、不领奖；露出后再按观察或捕捉规则互动。揭开进度可保存。
4. 鱼平滑转向、加减速，连续积分尾摆相位，速度变化不再使鱼尾跳帧。螃蟹横向侧行、交替停走，腿部局部摆动，甲壳稳定。涨退潮前提前寻找可达岸线，防止水位越过后卡住。
5. 三组错开的浪沿实际曲线依次推进、铺开与回落。高潮覆盖绝大部分低潮沙滩；低潮露出湿沙并保留潮池。高岸和礁石保留正确遮挡，细化右上礁石轮廓消除沙滩直切边。
6. 赶海底部工具改为「观察/捕捉、小桶、图鉴、潮汐、声音、设置」。正式潮汐按钮从当前水位开始涨潮或退潮，水位连续；海边声音面板复用原开关、音量和声场。锦鲤天气、日夜工具保留。

## 文件与运行

- 打开上一级 `打开摸鱼桌面.command`，或 `release/mac-arm64/浮生锦鲤池.app`。已打开的旧桌面程序需退出后重新打开。
- 上一级 `摸鱼桌面-2.1-完整源码.zip` 含源码、素材、测试与文档，不含 node_modules、构建缓存和桌面二进制；解压后按 README 安装和运行。
- 上一级 `赶海主题-高潮.png` 与 `赶海主题-低潮.png` 来自同一个不中断的自然加速周期；`赶海主题-窗口预览.png` 和 `赶海主题-桌面预览.png` 来自正式包。

## 素材与验证边界

现有17种透明动物素材继续使用，本次无需新增必需素材。海岸底图实际仍为1672×941，4K画布不等于原生4K底图细节。海胆、海参、弹涂鱼仍未提供素材，未伪装成已接入物种。macOS全局点击仍须用户自行授权辅助功能；本次未替用户授权。Windows/Linux原生桌面层与Apple公证不在本次验证范围。
