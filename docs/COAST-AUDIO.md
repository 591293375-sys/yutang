# 海岸环境声

海岸主题使用独立的真实海浪录音。与锦鲤池共用一个 `AmbientMixer`，随应用离线打包；不会从雨声转换或合成海浪，不需要联网播放。

## 离线处理

将预览解码为 48 kHz、16-bit、双声道 WAV，取第 20–116 秒。首尾使用 6 秒互补余弦交叉淡化，得到 90 秒循环。保持录音原本的速度、音高、海浪起伏与双声道关系。

采用固定平滑均衡：80 Hz 以下逐渐衰减以减轻低沉底噪，2.4 kHz 以上逐渐衰减以柔化海水泡沫的高频；未使用随时间变化的频谱噪声门。之后以 `0.05 * tanh(signal / 0.05)` 轻微软限幅，将平均 RMS 收低至 0.009，并在首尾各 10 毫秒修平采样接缝。所有处理均来自实地录音，没有加入随机噪声。

## 播放规则与接口

`useAmbient(enabled, volume, weather, season, night, theme = 'koi')` 增加可选的最后一个参数。`ambientMix(weather, season, night = false, theme = 'koi')` 和 `ambientDescription(weather, season, theme = 'koi')` 兼容原有调用。

海岸的海浪权重最高为主音量的 0.4；细雨、雷雨、雪、雾中分别为 0.30、0.28、0.24、0.32，夜间再收低 10%。海岸始终将溪流目标明确置零，锦鲤池始终将海浪目标明确置零，通过既有音量淡变完成切换。雨声沿用已制作的轻柔录音。

海风沿用已有实录风声片段并降低权重至最多 0.07，首次阵风在 60–120 秒后出现，持续 4.5–7 秒，之后留出 90–180 秒间隔。切换主题、天气、季节或关闭声音会取消旧阵风计时；切换主题会取消当前和待播的远雷。远雷只在雷雨天气允许启动，其他天气连静音预播也不会触发。主音量归零和禁用声音会停止相关声音。

每个媒体元素带有跨模块更新保留的所有权标记；过期 `play()` 完成后只能停止仍归当前实例所有的音轨。旧混音器被销毁后到达的回调不会让声音重新出现，也不能暂停接管同一元素的新混音器。天气／主题请求使用代际检查，避免延迟播放恢复已停用的音层。

`tests/coast-audio.test.js` 覆盖双向主题切换、旧播放请求延迟完成、跨主题远雷取消、非雷雨无雷声、阵风间隔重置与混音器替换。既有锦鲤池音频测试保持兼容。
