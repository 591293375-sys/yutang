# 猫咪庭院四季与日夜更新（v2.7 开发验证）

2026-09-30。此文档记录实际资源、实现与开发版验证，不代表已完成重新打包后的发行版验证。

> 以下是 v2.7 的历史记录。v2.7.4 已扩展中央石板地面的季节材质、落花与落叶；“中心保持不变”及其旧像素断言不再是当前产品要求。当前验证见 `../../work/cats/seasons-2.7.4/`（相对于项目根目录）的报告。

## 资源与渲染

- 春季新增 `public/assets/cats/art-v3/courtyard-sakura.webp`，内置图像生成编辑原场景得出，同构图的粉白樱花与边缘落花，实际分辨率 **1672 × 941**，WebP quality 92，**747,548 字节**。原始生成图保存在本目录 `sakura-source.png`，提示词见 `sakura-prompt.txt`。
- 图像生成工具未暴露模型选择，不能将结果标记为已确认使用特定 image2.5 模型。
- 夏季使用用户提供的原场景；秋季、冬季与夜景延用 art-v2 已生成的独立画稿。背景合成在资源/季节/时间变化时进行，渲染循环不逐帧重建高清背景。
- 季节画稿通过植被区域蒙版替换树冠、花丛和庭院边缘；中央石板、木廊、猫窝、水碗、石阶及爬架保留原坐标。春季并非单纯改色滤镜，实际替换为樱花树冠。
- 1920/3840/6144 档来自原始 8K 场景。新季节及夜景画稿是真实 1672 × 941；不将插值放大声称为原生 4K/6K 细节。夜景画稿中的细部清晰度仍受该原始分辨率限制。

## 环境交互

- 手动光阴仅“白天”“黑夜”，另提供“跟随本机时间”。自动规则为本地 07:00—18:59 白天，19:00—06:59 黑夜。
- 旧存档的 dawn/dusk 自动归一为 day；四季选择及粒子、萤火虫偏好保持不变。
- 春季花瓣随风漂移，秋季少量落叶，冬季少量细雪。地面落花/落叶和空中粒子分层绘制，夏季保持安静绿荫。
- 夜晚使用柔和蓝灰环境和宽缓月光，猫咪/道具接受现有统一场景环境处理。春夏夜间 9 个、秋夜 4 个、冬夜 0 个萤火虫，受开关、低动态及低性能模式限制。
- 所有效果使用现有单一渲染循环；没有独立计时器或 RAF。

## 已实际验证

命令（本机 Node 路径按环境配置）：

```sh
node --test tests/cats-environment.test.js tests/cats-geometry.test.js
node electron/cat-seasons-smoke.cjs
```

- 环境与坐标 **14 / 14 单测通过**：仅双时段、自动边界、旧设置迁移、素材路径、风中粒子连续变化、数量上限/低动态、萤火虫夜间限制与平缓亮度。
- Electron 开发版独立临时 profile 集成 **PASS**，通过真正 UI 切四季与昼夜，不使用用户存档。
- 1600 × 900 CSS 视口、3200 × 1800 渲染画布，四季树冠像素采样具有明显差异；中央石板采样差异小于 1 个 RGB 欧氏距离单位。
- 实际 UI 检查旧 dawn 设置恢复为 day；光阴只出现自动/白天/黑夜三项；夜景保持可见；萤火虫实际 Canvas 绘制随开关停止；重载后 spring/night/fireflies=false 保持；页面错误 0。
- 已逐张查看夏日、春日、秋日、冬日、春夜截图，确认春樱/秋叶/冬雪肉眼明显，夜间猫与地面明暗相容，小光点没有大面积光斑。
- 临时 profile 在退出后清理，未修改日常用户存档。

完整机器报告：`season-validation.json`。截图位于项目父工作区 `work/cats/v2.7/`：`summer-day.png`、`spring-day.png`、`autumn-day.png`、`winter-day.png`、`spring-night.png`。

## 主要文件

- `src/themes/cats/background.js`：季节植被合成与夜景补光。
- `src/themes/cats/environment.js`：双时段与旧设置迁移。
- `src/themes/cats/season-effects.js`：共享时钟的季节粒子及萤火虫。
- `src/components/CatPanels.jsx`、`src/themes/cats/cat-scene.css`：四季文案与双时段面板。
- `tests/cats-environment.test.js`、`tests/cats-geometry.test.js`：必要的环境与兼容性测试。
- `electron/cat-seasons-smoke.cjs`：独立 profile 的 UI、像素及绘制验证。

## 已知限制

季节原画在植被交界使用羽化蒙版，近看仍有不同分辨率画稿的笔触差别。庭院中心保留原场景的石板与固定日间树影，以保证高清细节和设施坐标；冬季活动地面保持可走的无雪区域。夜景主要使用已生成夜间画稿，非物理光照模拟。此轮未将发行包重新打包验证混为开发版通过结果。
