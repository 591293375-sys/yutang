# 连续局部动作修订（2026-09-30）

## 问题与修改

原图集的相邻步态帧由独立姿态构成，头部位置、体型轮廓和毛色边缘存在差别。逐帧切换或整猫交叉淡化，都会让可见毛色闪动；进食、洗脸的循环还会在不同姿态之间反复切换。待机与行走使用不同原画，也扩大了这种差异。

现在同一方向行走固定使用朝前第 0 帧或朝后第 4 帧，并在这张稳定的毛色纹理上进行连续局部网格变形。四足分别有支撑期、回摆和抬爪阶段；髋肩附近移动幅度小、脚端幅度大，同时保留轻微胸背起伏和尾巴随动。步相按实际移动距离推进，停下时不继续原地踏步。主渲染路径始终只画一个完整猫咪姿态，不以两张猫叠影代替关节动作。

进食、梳理、抓挠各使用自己的稳定姿态，分别移动头部或前爪。休息和睡眠只保留低幅呼吸。上下台阶保留接近时的朝向，并按游戏实际 crouch / jump / land 阶段做收拢、腾空、落地变化。短暂转向抖动有阈值和确认时间，待机沿用刚才的前后朝向。

自定义毛色与精确虹膜仍先绘制在对应动作纹理中，再随同一张纹理一起变形。网格权重和透明格占用信息缓存；占用缓存以实际图像对象隔离，避免瘦猫先缓存后错误裁掉胖猫或大耳朵的边缘。静止动作采用较稀网格。

## 修改范围与限制

主要文件：`src/themes/cats/continuous-rig.js`、`src/themes/cats/animation.js`、`src/themes/cats/renderer.js` 的 `drawCat`，以及动画测试和独立录像脚本。

这是基于已有手绘图的连续局部骨骼/网格动画，不是完整三维猫或重新绘制的多方向序列。主行走只有前、后两个真实原画方向，左右采用原有水平朝向处理。进入进食、趴卧等不同动作时仍需一次切换到对应原画姿态，辅以克制的收拢过渡；已取消动作循环里的反复整图切换，不能把它描述为任意姿态之间完全连续的三维形变。

## 背向后脚补齐（2.7.3）

继续逐张检查 16 款猫的背向 4–7 帧后，确认布偶、英短等原画只露出同一条后腿，远侧后腿被臀部遮住。对不存在的像素加大网格位移不能补出迈步，因此本次新增 `src/themes/cats/hind-leg.js`：从**同一只猫、同一份用户涂色与形态处理后的第 5 帧**提取真实后腿毛发和支撑爪局部，在固定躯干后方单独绘制。原画躯干不换帧，肢体不切换透明度，遮挡随位置连续发生。

两后脚相差半个步相，分别支撑、回摆和抬爪；髋部不随脚端一起平移。补出的腿有连续分段网格，原近侧后爪则根据实际 alpha 像素重新定位关节点，修正旧坐标偏右导致位移没有落在脚上的问题。左右后脚的支撑期重叠，避免同时悬空。上下台阶仍保持原方向，并沿用腾空收腿规则。

三花、黑白奶牛、挪威森林猫、暹罗、孟加拉原画已经露出两后脚；这 5 款不再补腿，而使用人工放大校准的髋、踝、爪坐标。其余 11 款补足远侧后腿。没有新增整张猫素材，也没有给不同品种套用同一条通用腿。日夜颜色缓存带材质修订号，确保夜景渐变中腿和身体一起变暗；不同毛色与胖瘦图像分别缓存。

本轮验证：

- 动画专项 20 / 20；连同外观保存与自定义参数共 27 / 27 通过。
- 独立 Electron profile 实际载入全部 16 套，输出每套背向四相；人工检查了全部 4 张汇总图。对比中没有把已有第二后脚的猫补成三条后腿。
- 100px 实际显示宽度，连续 120 个步相采样：新增可见远爪像素最少 89、最多 265，相邻步相的可见像素数最大变化 13。远爪没有整段消失再突然出现。对照通过绘图代理仅关闭独立腿层，保留完全相同的躯干网格，避免把其他关节点变化误计为新增脚像素。
- 胖瘦（0.80 / 1.25）、耳朵尺寸、身体和四肢涂色、白天与夜景的真实渲染检查；页面标题与 URL 正确、主界面非空、无框架错误遮罩，`pageerror` 为零。
- 测试入口 `node electron/cat-hind-leg-smoke.cjs`；采用隔离的 Electron / Playwright，因为 Browser plugin 不可用。未读取或修改用户日常 profile。
