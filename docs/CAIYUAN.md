## 运行与入口

在项目根目录执行 `pnpm dev`，打开 http://127.0.0.1:5188/，点击左上主题名称，选择「财源广进」。仍使用现有 React 19、Canvas 2D、Vite、Electron、localStorage 与 Lucide 图标。

已有桌面调试方式继续可用：开发服务器运行时，执行 `VITE_DEV_SERVER_URL=http://127.0.0.1:5188/ pnpm exec electron .`。原 `pnpm desktop` 命令会构建后运行桌面程序。

## 素材与坐标

实际采用用户目录中的 **空背景.png，7680 × 4320**。虽然文件名叫空背景，图中已含五位财神、完整「财源广进」匾额和红色祥云桌布。

- 母版：`source-art/caiyuan/final-background-7680.png`，连同原透明道具约 46 MB，位于运行时 public 目录之外。
- 运行资源：`public/assets/caiyuan/`，2K / 4K WebP 背景、10 张裁切透明道具和 manifest，图像合计约 3.2 MB；本次另加约 2.4 MB 本地音乐和添茶音效。
- **不加载**旧底图 `01_background_clean.png`、独立桌布 `02_table_runner.png`，也不使用旧 `背景.png` 设计参考作为场景。
- 处理脚本 `scripts/prepare-caiyuan-assets.cjs` 仅裁透明留边、缩放、编码和保存母版，没有重新绘制原图。
- 全部实体以同一个 1600 × 900 逻辑场景保存归一化坐标。背景采用 contain，额外区域为协调底色，因此不同窗口比例下完整保留五位财神与匾额。
- 桌面多边形、物件脚点、有效边界、缩放区间、烟火锚点均有独立定义。根据落脚点排序，命中反转完整绘制顺序，包含同深度重叠物件。

重制运行素材时需要已有 Sharp 环境：`SHARP_MODULE=<sharp模块路径> node scripts/prepare-caiyuan-assets.cjs <原始财神桌面目录>`。日常开发无需再运行此脚本。

## 2026-10-01 动效与声音细化

- 上方两侧红帷幔有约 10 秒的缓慢阵风、约 19 秒的停歇，固定边缘及悬挂点；只变形局部褶皱和流苏。缓存裁片按原图整数像素取样，避免风停时清晰度突变。
- 三支香各有连续烟缕和向上移动、逐渐散开的轻烟。风向缓慢变化，烟源随当前香头、移动和缩放；熄香保留当时发射高度，余烟约 3 秒散去。默认未点燃仍然没有烟。
- 莲灯火苗底部固定，轻微伸缩、偏转，暖光缓慢呼吸；夜间光晕更明显。暂停保持当前动效相位，减少动态将速度降为五分之一。
- 「设置」提供配乐开关、配乐音量、互动音效开关及添茶/轻响试听。总开关与原总音量仍生效，用户既有静音不会被自动解除。
- 原创无人声配乐时长约 3 分 14 秒，以低音量循环；开头、结尾与恢复播放做柔和渐变，互动音效播放时配乐短暂降低。AAC 文件约 2.3 MB，3 秒添茶 MP3 约 119 KB，全部本地播放。
- 声音同类限频、最多三个短音同时播放；隐藏、暂停及主题销毁停止所有声道。复用场景现有 RAF 更新声音包络，没有新增高频计时器。
- 消除了烟缕各分段重复经过 Canvas 明暗滤镜的开销；本机 2090 × 1798 渲染缓冲运行抽样约 51 FPS（单次测试数据，不代表所有机器稳定帧率）。
