# 1.3 天气、环境声与动态池岸

2026-09-27，Apple M5 / macOS 26 / Electron 37.10.3 arm64。

## 完成功能

- 手动天气为晴天、多云、细雨、落雪、雷雨。旧版手动雾天偏好升级为雷雨；自动天气的真实雾天保留正确映射。
- 多云、雨天有独立云朵倒影，沿水面缓慢移动。小纹理仅生成时柔化一次，不对大画布逐帧模糊。
- 每颗雨滴有独立飞行时间和目标位置，抵达后在同一位置产生两圈扩散水纹。雷雨更密集；落雨、涟漪、浮叶数量有上限。
- 雷雨首次约 8–14 秒出现很轻的天光变化，延后 0.9–2.1 秒播放远雷，之后间隔 23–45 秒。减少动态时关闭闪光。
- 真正的溪流、雨水、风吹树叶录音按天气、季节和昼夜混合。雷声单独播放；四个音频均离线打包，默认关闭。详见 [AUDIO.md](AUDIO.md)。
- 原背景水面的固定春秋叶片已清理，花瓣与浮叶独立漂流，偶尔落下并泛起小涟漪，受到鱼群和鼠标的轻微推动。
- 岸边草叶、树梢使用局部纹理变形随风摇动；水纹轻微流动。纹理层最高 4K 长边；锦鲤层保留桌面 4K 至 6K 像素预算。春秋图像是 4K 重采样文件，非原生生成的 4K 细节。
- WebGL 丢失或不可用时保留静态背景，不影响观鱼与投食；恢复上下文后自动恢复纹理动态。

## 逻辑与集成验证

54 项逻辑、模拟、渲染、存储、声场单元测试，以及 4 项桌面策略测试通过。新增覆盖落雨坐标、叶片入水漂流和长期数量上限、远雷间隔、减少动态、天气混音、关闭后静音、取消待播雷声、音量归零、快速开关及旧播放异步回调。

真实 Electron 集成验证：天气按钮替换、云影画面、雨滴与涟漪、真实音频实际播放、远雷实际播放、晴天停止雨／雷声、关闭和快速切换声音、动态背景像素变化、WebGL 上下文丢失与恢复、原生桌面模式。无页面异常。旧交互回归也验证了 57 秒水声循环越界、音量调整、快速开关、投食清除鼠标惊吓状态。
