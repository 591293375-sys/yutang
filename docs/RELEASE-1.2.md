# 1.2 交付与验证

2026-09-27，Apple M5 / 60 Hz 屏幕 / Electron 37.10.3。独立测试配置与用户的锦鲤、城市、偏好隔离。

## 修改

1. `useAmbient` 取消随机噪声，改用本地双声道溪流实录，57 秒循环。音量渐变，不依赖池塘动画帧率；默认关闭，遇到浏览器自动播放限制时等待用户的下一次点击。来源与处理见 [AUDIO.md](AUDIO.md)。
2. 窗口与桌面的分辨率策略分离。桌面标准模式至少 3840 像素长边，支持原生 5K / 6K，最大 6144×3456 等量像素；16:10 不裁切、不拉伸。本机实际桌面画布 3840×2486。系统窗口大小变化时重新计算分辨率，恢复普通窗口时显示上次桌面画布尺寸。
3. 投食感知从 550 像素内扩大到全池；远处加速、转向减速、临近食物制动、吃完恢复巡游。最高觅食速度约为对应季节 / 天气的巡游速度 3.4 倍，减少动态选项仍有效。清除投食点击之前残留的鼠标惊扰，之后的移动继续正常避让。

## 验证结果

- 44 项逻辑 / 渲染回归与 4 项桌面 IPC / 坐标测试通过。新增测试先在旧行为下失败，再在修改后通过，涵盖全池吸引、明显加速、近食减速、恢复巡游、投食清除惊扰、桌面超采样与 5K 原生像素。
- 实际 UI 验证溪流播放、音量调整、跨越 57 秒循环边界和快速连续开关，关闭后确实停止，无 JavaScript 错误。
- 24 条鱼的桌面画布测试，每项至少连续采样 5 秒：

| 实际画布 | 引擎帧率 | rAF 帧率 | p95 帧间隔 | >33.5 ms 慢帧 |
|---|---:|---:|---:|---:|
| 3840×2486 | 60 FPS | 59.99 FPS | 17.2 ms | 0 |
| 5120×2880 | 60 FPS | 60.00 FPS | 16.8 ms | 0 |
| 6144×3456 | 60 FPS | 60.00 FPS | 16.8 ms | 0 |

5K / 6K 使用真实 Electron GPU 与 DevTools 显示尺寸仿真，证明对应画布像素与渲染负载；本机没有外接实体 5K / 6K 显示器，未将仿真描述为外接屏实测。

- 打包后的 1.2.0 `.app`：4K 窗口连续 10 秒 59.90 FPS；3840×2486 原生桌面层连续 10 秒 60.00 FPS；两项均无 >33.5 ms 慢帧。安全 preload、桌面层、持续游动、控制恢复、四季图片及离线溪流文件解码通过。
- 本地应用签名验证通过。

实际表现依设备与负载变化。背景仍是 1.1 中重采样到 3840×2160 的四季图片，本次增加的是实时渲染画布分辨率，未声称提供原生生成的 6K 背景。
