# v4.1 · 舒缓海浪与猫咪动作

应用版本：4.1.0。此版本继续集成锦鲤池、赶海、猫咪庭院、财源广进四个主题，保留原有主 UI、存档键、设置与桌面模式。

## 本次修复

### 赶海

当前蓝色海湾美术的可见礁石轮廓与旧导航多边形不一致，导致鱼能游到出水岩面。现在从实际礁石透明度生成静态避障距离场，同时检查完整鱼身和路径；岩石前景遮挡使用同一材质。新图加载后，位于岩面的旧实例只就近移到安全处，保留原 ID、数量和奖励。石缝提示随真实岩缘定位。

海水使用独立水纹的连续形变与近岸推进浪，保持舒缓流动；没有晃动整张背景。潮汐周期、原岸线、水域范围、生成数量、捕捉及奖励规则保持不变。

本版包含此前已经在本地完成的赶海美术升级：分层海湾、独立水纹和浪花资源、透水光学及岩边效果，使用 `art-reference-v2` 资源。旧资源通过版本记录保留。

### 猫咪庭院

上下石阶、木廊和爬架采用用户选择范围内的简短渐隐渐显：从原支持点淡出，在安全目标点淡入。过渡中阴影同步，完全淡出时不拦截点击，落稳后恢复。平地行走继续保留，路径、任务与存档安全点机制不变。

背向行走补齐远侧前后腿，采用同只猫原画中的脚掌、毛皮与独立关节层，四脚前后交替。已画有四腿的外观不重复加腿，避免整只角色换帧闪动。仍然是二维原画动画；上下设施采用渐隐渐显，并非新增三维跳跃模型。

## 桌面包范围

提供 Apple Silicon Mac（arm64）桌面包。应用保持现有 ad-hoc 签名，未进行 Apple 公证；Windows/Linux 原生桌面能力不在本次实现范围。构建仍有既有的 JavaScript 主包超过 500 kB 提示，未因此改动共享框架。

本次生产环境检查中，外部 Open-Meteo 天气请求有一次网络失败，程序继续使用既有天气回退。本地资源和四主题加载不依赖该服务；本次未更换天气接口。
