# 猫咪庭院 2.7.0

本次按反馈调整已有主题，继续使用原来的工具栏、桌面窗口和本机存档。

## 外观与管理

- 移除猫咪管理中的“导入设计”入口。
- 创建流程改为“选猫咪 → 调整外观 → 看看它”；不再提供自由绘画。
- 可调大小（70%—135%）、胖瘦（80%—125%）、耳朵大小（75%—130%）与原本／圆润／尖俏耳形；眼色支持原色、预设色和自选颜色。
- 胖瘦与耳朵采用局部形变，保留原图质感；眼色只处理虹膜，保护瞳孔和高光。整体大小由庭院渲染控制，不重复烘焙进纹理。
- 亲人、活泼、悠闲、好奇、慢热、独立、贪玩、爱睡，共8种性格。移动速度和休息倾向有实际差异。
- 参数与名字随猫保存；缩略图、编辑预览和庭院共用参数。取消编辑不覆盖确认版本。新参数草稿独立保存。
- 旧猫已经确认的手绘毛色继续保留。旧画笔草稿不自动转成新参数草稿；锦鲤和赶海存档空间未变。

## 四季与日夜

- 春季使用新樱花画稿，花瓣沿风向缓慢飘落；夏季保留原来的绿荫绣球，秋季暖黄树叶，冬季庭边薄雪。
- 季节画稿只合成到植物区域，原始石板、石阶、草垫、水碗、爬架坐标保持一致。
- 光阴面板只保留自动、白天、黑夜。自动时07:00—19:00为白天，其余为夜晚；旧清晨／黄昏手动设置兼容为白天。
- 夜景有柔和月光、木廊暖光，猫咪与道具共同变暗。萤火虫仅夜间出现，春夏9只、秋季4只、冬季关闭；低动态最多3只。
- 环境粒子和萤火虫可以分别关闭，偏好本地保存。

## 动作

- 四相步态连续衔接，取消原先每帧大部分时间停住再快速切换的节奏。
- 对齐动作主体，减少步态之间大小和落脚点抖动；以实际移动距离驱动步相，腿部和尾部加轻微局部变形。
- 加减速有缓冲，急转弯会减速，水平朝向有稳定区间，抵达目标时逐步停下。
- 大小影响步幅、速度和猫咪间距。原来的归窝、暖石休息、道具互动与场景导航继续复用。

## 主要文件与边界

`CatStudio.jsx`、`CatManager.jsx`负责界面；`customization.js`、`morphology.js`、`storage.js`负责参数、贴图和兼容；`animation.js`、`game.js`、`renderer.js`负责动作；`background.js`、`environment.js`、`season-effects.js`和`CatPanels.jsx`负责四季日夜。

猫咪仍是有限方向的手绘姿态动画，并非三维骨骼模型。体型与耳形控制属于原画上的温和局部变形，不会替换猫咪品种。季节画稿约1672×941像素，和原始高分辨率设施合成；不将画稿宣称为原生8K素材。未在Windows或Intel Mac验证桌面发行包。
