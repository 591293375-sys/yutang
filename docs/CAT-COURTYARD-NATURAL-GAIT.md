# 猫咪庭院：天气、步态、爬架取景与轻风修订

2026-10-01。仅修改庭院模块及 App 中庭院天气入口；未修改其他主题的渲染、玩法与存储键。

## 改动

- 右上角复用锦鲤的城市、温度、天气及天气面板。庭院自己的四季、白天/夜晚仍从原工具栏设置。
- 四肢材质不再把采样的毛色填进程序胶囊和椭圆爪形。直接保留原画腿部 alpha、毛边和爪形，使用连续分段变形；后腿取自背面原画，单独定位落脚点。远侧腿沿用同一只猫的材质并略微减光。缩短步幅，保留按位移推进的四拍支撑、世界坐标落脚与真实台阶跳跃；平地没有新增整体弹跳。
- 庭院背景仍以原比例铺满窗口，横向裁切改为保留右侧设施。图片、猫咪、遮挡、阴影与命中共用原坐标变换，未搬移设施的存档坐标或重复叠加爬架。
- 从项目已有 CC0 风吹树叶录音制作 28 秒轻风：削弱持续底噪，保留三次渐起渐落的轻风及安静间隔，降低播放增益。取消风声合成噪声兜底；音源异常时保持安静，不逐帧重试。更新音源处理记录。

## 实际边界

这是已有二维原画上的连续关节动画，仍只有正背两组视向，不是完整三维角色。保持全屏等比显示时，较窄窗口会多裁去左侧背景，以保留右侧爬架。风声完成音源和实际音频图检查，听感仍会受用户音箱、耳机和系统音量影响。本次没有重新打包桌面安装包或发布项目。
