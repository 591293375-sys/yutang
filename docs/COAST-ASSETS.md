# 赶海主题素材说明

## 已使用的素材

用户提供的原始素材包为「赶海」。运行所需的副本已纳入 `public/assets/coast/`，构建不依赖提供者电脑上的原始目录。

| 素材 | 实际条件 | 应用内用途 |
| --- | --- | --- |
| `场景图.png` | 7680 × 4320，16:9，不透明、已合成的完整背景；水、沙滩、礁石、植物、泡沫和少量动物绘在同一张图中 | 以无损 WebP 副本 `public/assets/coast/coast-original.webp` 保留原图像素，作为风格与构图来源、加载失败时的后备背景 |
| `小动物设计图/` 中 17 张 PNG | 自带真实透明通道；单张约 1337–1536 × 1024–1176；每张是一幅独立插画，并非连续动画帧 | 原文件不改动地复制到 `public/assets/coast/`，运行时裁取有效内容并建立小尺寸绘制缓存 |
| `coast-low.png` | 以用户场景图生成的干净低潮地形，实际 **1672 × 941**；清除了绘死的动物与大部分固定浪花，并保留海岸、礁石和右下潮池 | 赶海主题的固定地形底图 |
| `coast-sand.png` | 2.3 新增，由 `coast-low.png` 经图像生成工具编辑，实际 **1672 × 941**、不透明 PNG；排去绘死的海水，露出细腻湿沙，保持构图与石头位置 | 仅替换原海水区域下方的地形，随后按实时潮线恢复海水，原沙滩和植物不替换；2.4.1 也用于对应出水岩面的原位前景 |

干净低潮图**不是原生 4K 底图**。应用能够建立 3840 × 2160 等高分辨率画布，动态泡沫、遮罩和动物按画布像素绘制；画布的输出尺寸不代表地形原图具有同等细节。诊断中的 `backgroundSize` 是背景画布的实际像素尺寸，`sourceSize` 单独报告底图的 1672 × 941 像素。

### V2.0 源码分发中的无损转换

完整场景后备图由 `coast-original.png` 转为 `coast-original.webp`，尺寸保持 **7680 × 4320**。文件由 **29,623,815 字节**缩减为 **21,593,866 字节**，以便通过网页上传源码。解码后 RGB 数据逐字节比较完全相等，没有重采样或改变画面；应用中的后备资源引用同步使用 `.webp`。

原 PNG 在本机交付工作目录 `work/coast-original-source.png` 另存，不随源码上传或应用打包。构建与运行只需要仓库内的 WebP，无需找回这个本机备份。此次转换不改变 `coast-low.png`、`coast-sand.png` 的尺寸或画面细节。

## 动物与贝壳清单

已接入的 17 种外观：小红蟹、沙蟹、寄居蟹、小海虾、银色小鱼、小丑鱼、青绿小鱼、黄尾小鱼、条纹小鱼、小河豚、蓝鳞小鱼、小章鱼、海星、扇贝壳、海螺壳、花背蟹、浅沙蟹。

文件映射、显示名称、大小、生境与裁切区域集中在 `src/themes/coast/catalog.js`。部分 PNG 含有几乎不可见的透明背景杂点，因此有效裁切区域按 alpha 大于 24 的内容确定；原始图片仍保持不变。

鱼虾通过连续脊线形变、独立摆尾与胸鳍动作建立动画帧缓存；蟹类按左右交替步态运动腿部，保持甲壳稳定。贝壳实例的位置和 ID 保持稳定：露出水面后在捕捉模式可拾取，被潮水覆盖后随水深柔和渐隐；浅水中即使仍能看见，也不能拾取。

## 运行时分层

原始背景没有提供独立图层，当前实现通过共同的世界坐标与遮罩完成分层，不需要等待额外素材才能运行。

| 层 | 当前实现 |
| --- | --- |
| 固定地形 | 原底图加对齐湿沙底层，保持沙滩、岩石和植物的构图稳定 |
| 常驻海水与潮汐水域 | 同一组海岸采样点驱动画面水域、生境判断和碰撞；高潮覆盖沙滩，低潮露出潮间带 |
| 水面质感 | 岸线距离场生成连续浅深水色，原地形纹理轻微折射，保留水下沙纹；细碎的透明浪舌沿实时岸线推进 |
| 湿沙 | 根据退潮后的覆盖范围逐渐淡出 |
| 浪花 | 沿实时海岸曲线独立绘制，不依赖底图内固定泡沫 |
| 右下潮池 | 独立且常驻的水域遮罩，低潮时仍保持水与适合潮池的动物 |
| 前景遮挡 | 使用与碰撞相同的出水岩石、岸角轮廓，按原图轮廓恢复前景；原海图里带水色的中央岩群与右侧岩面，从对齐的湿沙底图中恢复，水、浪花和动物均在石头后面；其余水下卵石仍允许游鱼经过 |

这些是运行时绘制层，不应将它们描述为用户提供了独立的水层、岩石 PNG 或干沙地形包。

### 2.3 湿沙图生成记录

输入为项目已有的 `coast-low.png`，使用内置 ImageGen 编辑生成。要求保持俯视水彩风格、相机、构图、全部礁石轮廓与植物位置；将青绿色海水替换为浅灰金色、奶油色细湿沙，保留少量较深湿痕，不增加动物、贝壳对象、文字或固定浪花。请求高分辨率输出，但工具实际返回 1672 × 941；未将放大画布描述为原生 4K 素材。

渲染时只使用原绘制海域内的湿沙内容，原画海水按同一水域遮罩恢复，避免整张背景缩放或独立动画造成岸石位移。完整手绘背景中的水下石头属于地形纹理；出水阻挡区域仍由 `geometry.js` 的同一组岩石轮廓管理。

## 可选补充

- 当前未提供海胆、海参、弹涂鱼素材，因此没有使用其他外观代替它们，也未把它们列为已接入种类。
- 可补充与现有构图、视角一致的**原生 4K 或更高分辨率干净低潮图**，提升大屏地形细节。适合的底图应无固定动物、无固定大面积泡沫，并保留同位置的海岸与右下潮池。
- 如未来提供单独的出水礁石、岸边植物或连续动物动画帧，可进一步细化遮挡轮廓和动作；当前功能不依赖这些附加素材。

可替换资源的具体规格：

| 补充项 | 尺寸与透明要求 | 约束 |
| --- | --- | --- |
| 更高清的干净低潮底图 | 3840 × 2160 或 7680 × 4320，不透明 PNG | 保持当前构图和海岸/潮池坐标；改变构图需要重新描绘 geometry.js |
| 海胆、海参、弹涂鱼 | 建议 1024 × 1024，RGBA PNG，背景完全透明 | 俯视角、单只完整动物、无文字/地面/不透明投影，沿用现有水彩风格 |
| 可选独立礁石/草叶 | 与底图同尺寸的 RGBA PNG | 原位对齐，仅目标前景不透明，其余完全透明 |

这些补充资源用于后续细化；本版实际使用的动态海水、湿沙、泡沫和遮挡已经完成，不以缺失图层占位。

### 2.4.1 岩石轮廓修正

未增加图片资源。`geometry.js` 的 `DRY_ROCKS` 以现有 1672 × 941 图像坐标描绘七个出水轮廓：中央五块岩石、中右大岩石及相连上方石块、右侧小岩石。轮廓统一转换到 1600 × 900 世界坐标，合并进入 `ROCKS`。渲染器在海水、动物和浪花之后恢复同位置的岩面，原海水底图里画死的青色不再覆盖出水岩面。海岸涨退潮控制点保持不变。
