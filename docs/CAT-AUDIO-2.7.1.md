# 庭院声音修复 · 2.7.1

## 修复与操作

- 首页「声音／静音」直接开关；明确开启时若音量为零，恢复为 30%。保留历史静音设置，不自动改写。
- 设置显示实际的待唤醒、就绪、播放、静音或错误状态；七种试听分别对应猫叫、呼噜、进食、毛线球、抓板、羽毛和玩具小鼠。
- 轻抚不再先播放点击喵声而占用唯一音频通道；互动到达事件负责播放道具声音。忙碌时最多保留一个可替换的反馈，旧反馈不会无限排队。
- 小声脚步根据实际行进距离触发，落地也有反馈；同类声音限频。
- 白天偶尔鸟鸣（常态间隔 45—90 秒，秋季 70—110 秒），夜间稀疏虫鸣（70—120 秒），冬季关闭这些环境声。没有持续白噪声或背景循环。
- 静音、音量零、隐藏、暂停、编辑和主题销毁均停止当前声音与待播反馈；音量调整作用于正在播放的声音。

所有声音是本地合成 PCM，非实录猫叫；不需要网络或新增音频下载。首次在浏览器播放需要一次真实用户点击，若状态显示「等待轻点唤醒」，点击声音或试听按钮。

## 实际验证（2026-09-30）

- 348 项单元测试、5 项桌面策略测试通过，其中声音模块 12 项，包括增益、峰值、限频、排队、取消、环境调度与静音竞态。
- 开发版真实场景点击：首次轻抚启动呼噜；食物、猫抓板、毛线球、小鼠和逗猫棒在到达互动后启动各自声音。隐藏、静音和换主题清理通过，页面错误 0。
- macOS arm64 正式 2.7.1 包（file://、app.isPackaged=true）七种试听均测到非零 WebAudio 输出；静音与零音量停止声源，重载保留偏好，切换赶海关闭猫咪音频上下文，页面错误 0。
- 开发版与正式包 UI 各 7 项检查通过：静音旧档、启用恢复音量、试听、音量百分比、重载、390/1200 像素布局、锦鲤共享偏好。
- 默认 30% 音量：呼噜全段输出 RMS 0.0400；猫叫 0.0508。最大音量各声音峰值小于 0.33，保留余量。测试检测的是数字音频图的输出，不是物理扬声器响度或主观音色听评。
- 正式包 3726 个归档文件完整性检查通过，macOS 代码签名验证通过。未做 Apple 公证。
