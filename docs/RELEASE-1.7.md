# 1.7 轻雨、桌面清晰度与连续游姿

2026-09-27，Apple M5 / macOS 26 / Electron 37.10.3 arm64。

## 修改

### 轻雨声

换用 [lukabea 的 Rain.WAV](https://freesound.org/people/lukabea/sounds/707672/)（CC0）中平稳的轻雨片段。采用固定的平滑均衡、工频抑制、柔和峰值处理及无缝循环；去掉旧素材处理流程中随时间变化的逐频点噪声门，避免叠加频谱伪影。保留自然雨水的宽频成分，不添加白噪音。

输出仍为 45 秒离线立体声 WAV，平均电平相对 1.6 下降约 14.4 dB，峰值从 0.363 降至 0.0234，高于 4 kHz 的频段能量下降约 16.6 dB。细雨与雷雨的混音权重分别收低至 0.34／0.40。风声仍是此前的偶发阵风，远雷逻辑不变。

这些是信号测量和实际播放验证；本环境没有可用的音频听觉输入，未声称已人工试听或消除了所有自然雨声的噪声成分。来源、许可、处理参数及脚本见 [AUDIO.md](AUDIO.md)。

### 桌面清晰度

先前只有鱼群使用 5K／6K 画布，背景仍被单独压在 3840 长边，在更高像素密度下会被二次拉伸。本轮让背景和鱼群共用像素预算；读取 Electron 实际显示缩放，监听仅 DPR 改变但 CSS 窗口大小不变的情况。背景实际尺寸从 WebGL drawingBuffer 读取，设置同时显示鱼群与背景尺寸。

背景加入小幅软边校正（每通道限制约 4.6/255），不会把整幅池塘重新变成位移动画。超过 4K 像素预算时只将植物背景更新采样降至 30Hz，保持原生尺寸；鱼、水波与雨幕仍以 60Hz 目标运行。低功耗模式维持显式低分辨率，较弱 GPU 按其画布上限等比例分配。

背景文件仍为 3840×2160，底图细节受原始插画分辨率限制。本次解决额外拉伸和 DPR 失配，没有宣称生成了新的真实 4K／6K 纹理细节。

### 鱼的连续游姿

原身体波从尾向头传播、固定摆幅，与游速无关；转向会直接切换角速度。现在由肩部向尾部延迟传递摆动，头部保持稳定；摆幅、摆尾频率随速度平滑变化，并加入每尾不同的滑行节奏。尾鳍顺接尾柄切线，左右胸鳍独立轻划、辅助转弯；转向先建立再释放角速度。投食冲刺、大小和自绘花纹保持。

## 验证

- 81 项前端／模拟／音频测试、5 项桌面策略测试通过。新测试包含肩部到尾部的波传递、30／60 帧动作一致性、转弯无突跳、尾鳍衔接、冲刺到巡游、减少动态、背景同像素、换屏 DPR 更新，以及雨声电平与无缝接缝。
- 实际 Electron 中投食前平均速度 18.25 px/s，投食 1.8 秒后约 58.50 px/s；摆幅参数由 0.0478 增至 0.0798，35／36 尾鱼的尾部明显移动。
- 新雨声在 Chromium 中实际加载 `rain.wav?v=1.7`、解码与播放，45 秒循环，峰值 0.0234、RMS 0.00313；关闭后全部音轨停止且音量归零。
- 保留 1.6 的全屏降雨、固定池底、植物局部风动和岸边细波。水底／干石的像素差仍为零，枝叶区域变化；雨滴覆盖全部 4×4 视口区域。
- 满池 24 原生鱼 + 12 自绘魚 + 4 乌龟、雷雨，预热 1 秒后采样 6 秒。采样时不截图、不回读像素。

已重新打开用户原资料的最终应用，并在设置界面确认版本 1.7；昆明、14 尾鱼（12 原生 + 2 自绘）、声音开启与 40% 音量保留。浏览器预览也确认显示 1.7，现有偏好保留，未替换用户收藏。
