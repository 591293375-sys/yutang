# 2.4.1 礁石与潮水修复记录

## 实际改动

- 右侧小石头的原椭圆遮罩偏离真实轮廓，现按原画重描，去掉外围错位的水色补丁。
- 补齐中央五块岩石、中右大岩石与相连小石、右侧小石的前景。出水岩面取自既有的对齐干沙图，恢复在海水、动物与浪花之后；涨退潮不再切开岩面。
- 前景与碰撞共用 `DRY_ROCKS` / `ROCKS`，统一 1600 × 900 场景坐标。原海岸涨退潮曲线不变，没有增加图片资源。
- 螃蟹退潮寻找低潮岸边，路径检测避开细小石角；鱼群从不同合法海面入口进入，觅食点预留身体和转向空间。
- 旧存档落入新岩面的贝壳按原 ID 迁回合法沙地；失效石缝鱼同步重建鱼位、锚点和出口。保留所有收藏与救助计数，重载后位置稳定。

原地形图仍为 1672 × 941。4K 指实际输出画布，不表示原画新增了 4K 细节。
