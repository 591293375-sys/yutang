# 猫咪庭院 · 2.6.0

此页为2.6.0历史交付记录；本次调整见 [猫咪庭院2.7.0](CAT-COURTYARD-2.7.md)。

2026-09-30。本轮在现有 React / Canvas / Electron 程序中完善猫咪主题，沿用主 UI、窗口、设置与三个独立存档。原始庭院 7680×4320 图片和历史猫咪毛色坐标保留。

## 实际实现

- 16 个独立外观：12 个品种外观，以及同属中华田园猫的橘白、三花、狸花、黑白奶牛。补画波斯、异短、孟加拉、阿比西尼亚，未用其他品种改名。
- 每款独立的16姿态透明图集：前向四相步态、后向四相步态、伏卧、蜷睡、低头进食、舔嘴、洗脸、舔爪、伸展抓挠、伏低扑玩。右向通过水平镜像；不旋转整张猫图。步态随实际行进距离推进，停车时脚停止。
- 动作按每个主体真实 alpha 边界定位，修复生成图不等行高导致的切脚、断尾。动作切换短暂过渡；休息有轻微呼吸，进食和洗脸有局部微动。
- 自定义毛色按头、身体、尾、四肢分区映射到姿态，使用原画笔色与覆盖率、动作自身明暗，保留 alpha 和五官。避免通过 RGB 差值在白肚皮产生错误颜色。
- 初始3只猫；最多12只同时在场。回窝会走过石阶与木廊，到草垫、暖石或安静石板处休息，猫仍在画面中。轻轻叫醒恢复活动；单独的「收回收藏」用于释放在场位置，保留名字、涂色及记录。
- 草垫、石阶、木廊、暖石、水碗和爬架下层都有真实落脚面、通行连接与点击区域。床沿、石阶与平台前沿用原图像素遮挡，猫身下有接触阴影。
- 爬架下层限一只猫：先走到起跳处，蹲伏、沿弧线跃起、落稳、伏卧；唤醒或新指令先跳回合法空地。占用、连续命令替换及重载不会把猫留在半空。上层平台不在本期可交互范围。
- 六种道具：食物、毛线球、猫抓板、逗猫棒、玩具小鼠、轻抚。点击指定猫或可达区域，道具选择保留；新命令替换旧任务。食物最多两只，抓板最多三块，持久抓板可移动/收起。全部临时对象有上限和寿命。
- 涂色编辑、头身尾四肢区域、对称、缩放平移、擦除、撤销重做、名字和性格、保存/取消、草稿、本地设计导出导入延续原功能。
- 独立春、秋、冬及夜景画稿。季节植被与原高分辨率地面/设施合成；夜景画稿移除强白天叶影，猫和道具接受相应光照，夜间萤火虫可关闭。四季/时间自动或手动选择持续保存。
- 柔和本地合成短喵、呼噜、进食与道具轻触，单声源、同类限频、无持续噪声。静音/暂停/隐藏/离开主题立即停止声音。
- 窄窗、竖窗、超宽屏使用同一个等比完整场景坐标变换，设施可见且点击对应；不在每帧更新UI或写存档。隐藏和主题切换清理动画/监听/临时道具，继续复用现有桌面穿透及窗口桥。

## 启动与使用

```sh
pnpm dev                 # http://127.0.0.1:5188/
pnpm desktop             # Electron开发运行
pnpm package:mac         # Apple Silicon macOS应用
```

左上角切换「猫咪庭院」。底部：猫咪、道具、四时、光阴、庭院、设置。猫咪管理中点「回窝休息」后会关面板，以便直接看到走回草垫的过程。「庭院」可指定草垫、暖石、石阶、低爬架和水碗，也可点击场景里的设施。选择道具后点猫或地面；Esc结束临时互动。

桌面包位于 `release/mac-arm64/浮生锦鲤池.app`，项目旁 `打开摸鱼桌面.command` 指向该包。浏览器预览和桌面应用各自使用本地存储；新版沿用同一应用ID，不清理旧存档。

## 数据与主要文件

`mofish-cats-v1` 保存猫ID、预设、名字、性格、外观版本/笔迹、在场状态、休息意图与位置、抓板和环境；`mofish-cats-draft-v1` 保存未确认草稿。`mofish-theme` 继续记录最后主题。锦鲤、赶海、漂流瓶原键不迁移、不重置。半空跳跃按安全端点保存，重开重新协调路径，不补演离线互动。

## 素材来源与边界

- 本轮使用内置图像生成工具；工具未提供指定/确认“image2.5”的型号接口，不能声称已调用该具体型号。prompt、PNG原稿、WebP和检验记录均归档在 `docs/cat-art-v2/`。
- 16套动作图集合计8,481,080字节，约8.09MiB；四季/夜景与4款新外观约3.05MiB。原稿PNG和开发试听WAV不进入发行包。
- 原用户背景是7680×4320；运行原景选择1920/3840/6144档。新增季节/夜景画稿真实为1672×941，四季以原景高分辨率设施/地面加新植被组合，并非每个季节均有原生8K整幅画。
- 当前是有限方向、四相走路与手绘姿态过渡，真实脚部动作已实现；不是三维全向骨骼模型。涂色采用稳定身体分区UV，不承诺每根毛发在全部姿态逐像素相同。
- 爬架开放下层；上层不作为可点目标，不让猫穿过立柱“飞”上去。
- 反馈声是本地合成，不是真猫实录。已做信号/生命周期检查，未宣称真人听感验收。
- macOS原生权限系统弹窗与用户真实全局点击授权不在隔离自动测试内；现有能力继续保留。Windows/Linux原生桌面层仍沿用项目既有平台限制。
