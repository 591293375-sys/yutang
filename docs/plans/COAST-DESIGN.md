# 摸鱼桌面 · 赶海主题

目标：在既有 React/Canvas/WebGL/Electron 应用中增加可切换的海岸主题，复用 HUD、Panel、设置、窗口桥、天气和声音。用户已授权常规细节自主决定并按三个阶段完成。

共享壳：App 保持挂载；最小主题注册表含 koi、coast。所选主题使用独立 mofish-theme 键，老存档无该键时默认 koi，fusheng-settings/fusheng-fish 与 Electron app ID/userData 不改。各主题场景组件 keyed remount，卸载主动保存并销毁动画/监听/音频回调。

海岸数据：固定 1600×900 世界坐标，cover 视口变换。海岸模块维护明确的高低潮海岸曲线、陆地/礁石多边形和潮池。queryHabitat 与背景水域遮罩引用同一批采样点。潮水覆盖原干净低潮底图的沙滩，以源图海水纹理、缓慢明暗与曲线浪花绘制；遮挡区裁切海水和动物。底图缺层通过非破坏式图像生成补齐并记录源图分辨率。

潮汐：持久化 epochMs；1800 秒周期阶段 600/300/600/300，余弦缓动，阶段连续。离线直接协调当前状态；不补演或发放离线奖励。开发模式调试时钟只影响临时虚拟时间，不写永久时间起点。

实体：稳定 ID，scene/bucket/rescuing/releasing/collected/departed 状态与 submerged/stranded 标志正交。最多 52 活体（包含桶内）、24 贝壳、12 桶内活体；每轮退潮最多3次由原有鱼虾转换的近岸搁浅。操作同步占用目标，动画只是已确定结果的表现，防止重复奖励。存盘把 transient 状态协调为有效稳定状态。每轮新对象有限补充，以新 ID 生成。

观察/捕捉：普通动物回应并解锁；观察下露出沙的贝壳永久收集；观察搁浅鱼虾救回合法水域；捕捉活体占用桶格，不随机失败；放生按生境找合法点，失败留桶。图鉴记录首次发现、观察/捕获/拾取/救助次数。

UI：原 HUD、字体、面板、玻璃色不重设计；品牌旁主题入口；赶海工具栏含观察/捕捉、小桶、图鉴、天气、日夜、设置。小型潮位状态显示阶段/下阶段时间/水位。设置隐藏鱼塘专属数量/绘鱼并保留通用开关。开发专用潮汐面板用 import.meta.env.DEV 门控。

验证：潮汐边界与同位置水域判定、一个完整60倍周期、搁浅/涨潮恢复、连续点击和满桶、单/种/全放生、离线重载、快速主题切换清理、旧存档、缩放点击/桌面穿透；实图高低潮截图和4K性能，生产包无调试面板。
