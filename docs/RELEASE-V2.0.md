# GitHub V2.0 · 摸鱼桌面合集

## 版本含义

V2.0 是本仓库「锦鲤池 + 赶海」合集的 GitHub 发布里程碑。内部应用版本继续使用 `2.4.1`，应用文件仍叫「浮生锦鲤池.app」，不是将内部版本降回 2.0。`package.json`、历史更新说明与存档格式不因本次里程碑命名而重置。

原有的 [内部 2.0 记录](RELEASE-2.0.md) 描述赶海最初接入；后续 2.1–2.4.1 是持续迭代历史。本文件描述本次源码合集范围及发布核验状态。

## 本次源码范围

- **共享应用与 UI**：同一入口切换锦鲤池、赶海，沿用主界面、面板、音量、减少动态、暂停与桌面控制；启动恢复上次主题，两个主题分别保留自己的场景与收藏。
- **锦鲤池**：鼠标避让、投喂聚集、自绘花纹映射到锦鲤、不同体型与小乌龟，保留四季、天气、日夜与随环境变化的声音。
- **潮汐与海岸**：默认 30 分钟一轮，涨潮 10 分钟、高潮 5 分钟、退潮 10 分钟、低潮 5 分钟；手动操作从当前潮位立即连续涨退。水域、动物生境、浪花、沙画冲刷与点击使用共同场景坐标。退潮露出湿沙，潮池保留海水，岩石前景不被潮水切开。
- **赶海生物**：17 种已有外观，包含蟹、寄居蟹、鱼、虾、章鱼、海星和贝壳；鱼尾与鱼鳍、蟹腿分部运动。动物按生境进入、避障、躲藏或搁浅，旧岩石附近的失效位置有存档迁移处理。
- **观察、捕捉与收藏**：观察时回应或救助搁浅鱼虾；捕捉模式拾取贝壳与捕捉动物。游鱼会先躲闪，搁浅鱼虾可一次拾取。小桶容量 12，支持单只、同种及全部放生；图鉴、贝壳和救助记录保存在本机。观察模式长按沙滩可画画，海浪经过后冲淡笔迹。
- **漂流瓶与信纸**：收集来信、阅读 29 张不重复的手写信纸；在同一张纸上打字、画画、擦除、撤销并放流。保留草稿、收藏和放流记录。信件与绘画仅在本机保存，没有跨用户发信服务。每轮自然涨潮、或手动由退转涨时来一瓶，同一段涨潮不会重复生成；已有未拾取来信瓶继续保留，不替换或叠加。29 封来信收齐后停止投放，离线涨潮不补发。
- **桌面壳**：macOS 主屏桌面层、鼠标穿透、菜单栏恢复、可选全局点击互动；普通窗口可拖动、缩放、全屏、最小化、隐藏或退出。浏览器可预览全部场景互动，但不能代替系统桌面层。

仓库保留 `src/`、`public/` 离线素材、`electron/` 源码和原生头文件、测试、构建配置、锁文件与开发文档。`开发提示词.md` 是保留的早期开发参考，运行与构建以当前 README 和代码为准。不提交 `node_modules/`、`dist/`、`release/`、原生二进制、个人配置、用户存档或临时测试档案。

## 素材分发调整

完整场景后备图使用无损 `coast-original.webp` 替代原 PNG。尺寸保持 7680 × 4320，解码后 RGB 数据逐字节相等；文件从 29,623,815 缩减为 21,593,866 字节，适配网页上传的单文件大小要求。运行时代码已引用 WebP，原 PNG 仅保留在本机工作目录 `work/coast-original-source.png`，不上传、不打包。转换没有增加原画细节，也不改变潮汐地形底图。完整记录见 [赶海素材说明](COAST-ASSETS.md)。

## 在另一台电脑运行与复验

先按 [README](../README.md) 安装 Node.js、pnpm 和依赖，再执行：

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm test:desktop
pnpm build
pnpm dev
```

在 Apple Silicon Mac 上，准备 Xcode Command Line Tools 后，可以另开终端进行桌面构建与界面检查：

```sh
pnpm package:mac
node electron/coast-bottle-smoke.cjs --packaged
node electron/coast-capture-smoke.cjs --packaged
node electron/coast-rocks-2.4.1-smoke.cjs --packaged
node electron/packaged-smoke.cjs
```

这些命令是复验入口，不表示本轮全部已经执行。GUI 检查需要真实图形桌面。桌面桥接、架构与权限说明见 [electron/DESKTOP.md](../electron/DESKTOP.md)。

## 已知边界

- 原生桌面层目前仅实现 macOS，既有实际验证平台为 macOS arm64。Windows/Linux 可运行网页和普通窗口；Intel Mac 构建、全局点击授权及登录启动需要对应环境另行验证。
- 默认 macOS 打包采用 ad-hoc 签名，未使用 Apple Developer 证书或完成公证。
- 赶海地形底图为 1672 × 941；可输出 4K 画布，但不等于背景增加了原生 4K 细节。素材与可选高清替换要求见 [赶海素材说明](COAST-ASSETS.md)。
- 既有 2.4.1 4K 样本常态约 60 FPS，手动涨潮约 59 FPS，但有一次约 250ms 帧间隔；不承诺所有设备全程无停顿。
- 天气与城市查询需要网络，失败会回退；场景、动物、声音及信纸随源码提供，可离线使用。网页版与桌面版的本地存档独立，克隆源码不会迁移原电脑的个人收藏。
