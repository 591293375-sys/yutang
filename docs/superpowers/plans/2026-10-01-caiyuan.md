# 财源广进 Implementation Plan

**Goal:** 在当前 React/Canvas/Electron 项目接入独立、离线、可保存的第四主题。
**Architecture:** caiyuan 目录包含 catalog / geometry / model / storage / renderer / audio / Scene / Panels / CSS；共享仅更改 App 分支、注册项、主题卡图标与通用设置标签。
**Tech Stack:** 现有 React 19、Canvas 2D、localStorage、Electron、node:test、Playwright/Electron。
**Spec:** 本次用户十四节完整需求；最终背景为用户文件夹中 7680×4320 的空背景.png（实际已带桌布与财源广进匾额）。

## Global Constraints
- 保留 3.1.0 当前工作区和前三主题；不发布、不更新远端、不改既有存储键。
- caiyuan 采用 mofish-caiyuan-v1，初始化标记与空布局分开，尺寸位置归一化。
- 前景仅使用03–12透明素材；原图留 source-art，运行时2K/4K和裁切WebP。
- 场景 contain 映射，背景、道具与命中共享；24件上限、香炉唯一。
- 纯文本心愿60字，至少30祝福按本地日期稳定；离线不补播完成音。

## Review Focus
1. 删除全部与损坏存档的区别：不能空桌自动补满；只修复自身命名空间。
2. 燃香过程中移动/缩放/收纳/撤销、系统时间回退：不会重叠计时或串位。
3. 超宽和16:10的落脚点、香头、火苗与命中仍对齐，完整牌匾和五人可见。
4. 面板与静心时点击不误放物件；拖动取消与无效位置不改变存档。
5. theme快速切换、隐藏/恢复：图像迟到回调不能绘制旧主题，无残留音频/RAF。
