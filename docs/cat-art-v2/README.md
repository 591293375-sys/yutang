## 坐标与视觉核对

- 未改动原有 12 个外观的裁切、版本和坐标，避免历史涂色偏移。
- 四张新猫原画统一增加 16px 透明边，再缩为 768 / 256；归一化点为 `(原坐标 × 1254 + 16) / 1286`，纹理和缩略图一致。
- 仅清除小于 8/255 的极低透明噪点，保留其他毛发半透明边；没有通过脚本重绘猫咪。透明背景由图像生成工具直接输出。
- 新猫登记独立毛长、体型、脸型、耳、尾、移动速度、场景比例；四个田园花色继续统一归属 `domestic`。
- 逐张检验头、躯干、尾和四肢的辅助区域，以及两个眼睛与鼻嘴的保护椭圆。保护中心均落在可见猫身内。可视审阅图见 [protection-review.png](protection-review.png)，机器检查结果见 [validation.json](validation.json)。
- 当前16个ID均唯一，所有纹理/缩略图存在且带 alpha，区域坐标全部在0—1范围。

## 分辨率与剩余限制

新季节和夜景原图真实分辨率为 **1672 × 941**。没有升采样成 3840 / 6144 伪称高清原稿。原用户夏日庭院的 7680 × 4320 原稿仍保留；运行可按 1920、3840、6144 像素档使用，并保留高清石板、廊沿与设施坐标，只合成季节植被和光照变化。生成画稿与原图总体构图相同，但不应把生成结果当作逐像素精确遮挡蒙版；交互设施应依照原图坐标。

如要求每个季节的所有植物边缘与完整夜景也达到原生4K，需后续高分辨率绘制。当前新猫是独立 canonical 站姿，真实动作表现由另外生成的 atlas 接入，不由这些单图自身提供。多方向连续步态、更细致的动作UV和真实音效录音仍需以独立清单及运行报告为准。

## 重复压缩

开发环境提供 `sharp` 后：

```sh
node scripts/prepare-cat-art-v2.cjs docs/cat-art-v2/sources
```

脚本仅执行固定透明边、极低 alpha 噪点清理、缩放和 WebP 编码，不生成或重画美术。构建和运行不依赖 `sharp`。
