下载使用各来源页公开提供的 HQ MP3 预览；转换为 48 kHz、16-bit、双声道 WAV，峰值统一至 0.65。处理脚本存放在 `scripts/prepare-weather-audio.py`，输入为使用系统 `afconvert` 转换后的 WAV。所有声音随应用打包，播放无需联网。

晴天按春夏秋冬调整溪流与风声比例；秋冬风声较多，冬季流水更轻。多云增加微风，细雨突出轻柔雨水，雷雨增加风雨与独立远雷，雪天保留低缓冬风。夜晚略收低整体层次。切换使用平滑音量过渡，不重启正在播放的溪流。每层音量预算之和不超过主音量；雷声另以主音量 0.62 倍播放。全局音量上限沿用 0.6。

雷雨开始约 8–14 秒后首次出现低亮度天光变化，约 0.9–2.1 秒后传来远雷；后续间隔约 23–45 秒。声音开关默认关闭。关闭声音、主音量归零或切出雷雨会取消待播雷声；关闭后所有循环淡出并停止。减少动态模式不闪光，保留轻缓雨声与远雷。

## 1.5 安静声场与间歇阵风

对上述同一批 CC0 溪流、雨水、风声做离线频谱降噪：2048 点、512 点步长的重叠变换，以每频带 22% 分位数估计持续底噪，平滑频谱增益避免孤立音调；柔化溪流 2.4 kHz、雨水 2.9 kHz、风声 1.6 kHz 以上的高频，滤去 75 Hz 以下低沉杂声。保持原有循环交叉淡化、采样率和时长，不叠加噪声生成器，也不重新放大降噪后的底噪。

以处理前文件为基准，前 8 秒 4 kHz 以上频带能量分别降低约 28.8 dB、25.5 dB、39.6 dB；这是频谱测量，不能等同于所有听感杂声均为零。水流和雨滴原本就含自然宽频成分，保留其流动细节。

风声文件不再循环。开启声音后 60–120 秒首次轻轻出现，目标音量维持 4.5–7 秒后淡出至停止；后续等待 90–180 秒再播一小段。春夏秋冬改变流水和阵风的轻重，风声最高只用主音量的 14%。关闭声音、音量归零、切换天气或季节时取消当前阵风及待播计时器。

新处理的三个录音使用 `?v=1.5` 资源地址，确保已打开过旧录音的窗口能加载新文件。原始谱量验证保存在本次工作目录；可复现处理脚本为 `scripts/clean-ambient-audio.py`，使用 Python + NumPy。


## 1.7 重新制作轻雨录音

旧雨声源带有雨打伞面的密集敲击纹理。为避免反复频谱降噪造成沙砾感／音调伪影，本次替换雨声素材，而不是继续叠加降噪遮罩。

- 新来源：[Rain.WAV — lukabea](https://freesound.org/people/lukabea/sounds/707672/)，作者描述为 pleasant evening rain；2026-09-27 核验页面许可为 [CC0](https://creativecommons.org/publicdomain/zero/1.0/)。
- 输入为该页公开 [HQ MP3 预览](https://cdn.freesound.org/previews/707/707672_2407572-hq.mp3)，转换至 48 kHz / 16-bit / stereo。
- 取 20–68 秒，3 秒互补余弦交叉淡化，形成 45 秒循环。固定、平滑的高通／低通均衡及窄带工频抑制；不使用随时间变化的逐频点噪声门、不添加合成白噪音。轻微软限幅缓和突兀敲击，精确修平循环首尾。
- WAV 平均 RMS 从旧版 0.01644 降至 0.00313（约 −14.4 dB），峰值从 0.363 降至 0.0234；前 8 秒 4 kHz 以上能量约 −16.6 dB。这是客观信号指标，不代表主观听感或所有自然雨声成分完全无噪声。
- 细雨层权重从 0.48 收低至 0.34；雷雨由 0.54 降至 0.40。仍保留柔和溪流、既有偶发阵风和远雷；风声频率不变。
- 雨声文件使用 `rain.wav?v=1.7` 避免旧缓存；完全离线打包。处理脚本：`scripts/prepare-gentle-rain.py`；信号指标：[rain-audio-1.7.json](performance/rain-audio-1.7.json)。


## 1.9 稀疏鸣叫与雷雨播放保护

没有新增虫鸣合成器或随机噪声。原溪流素材本来混有鸟类等自然环境声，旧 57 秒循环中含两段密集的约 500 Hz 低频鸣叫。本次使用同一份 CC0 原录音，挑选更长的流水段，保留 75–79 秒的一小段鸣叫，以 1.5 秒互补余弦交叉淡化连接，制作 120 秒循环。源码脚本为 `scripts/prepare-sparse-stream.py`；采样率 48 kHz、双声道，未改变速度或音高。

使用固定平滑高通／低通与轻微软限幅，避免时间变化的频谱噪声门；保留连贯流水，并柔化孤立峰值。循环首尾采样一致。只用于对比的低频持续音活动检测（465–585 Hz 与 800–1600 Hz 功率密度之比，持续至少 160 毫秒）由每分钟约 37.9 段降至约 3.5 段；它不是物种识别，也不代表主观听感评分。WAV RMS 由 0.00794 变为 0.00547，峰值由 0.203 降至 0.04395。新版地址为 `healing-stream.wav?v=1.9`。

雷声在安排播放、实际媒体启动及异步回调完成时都检查雷雨状态。晴天等非雷雨天气不再启动静音预播；切换天气、关闭声音、音量归零会立即暂停并复位雷声音轨。旧实例的异步回调不能干扰新版实例。风声、雨声和远雷素材、既有阵风间隔保持不变。

验证使用真实 Chromium 媒体播放状态和离线信号分析；没有声称完成真人试听。93 项逻辑／桌面测试以及 `electron/sound-1.9-smoke.cjs` 的天气切换与静音检查通过。
